# 模块：动图与视频互转（sticker-video）

> 更新记录：v0.1（2026-09-18）新增模块（用户需求：「动态表情包转视频」与「视频转动态表情包」）。

## 目标
双向互转，方向自动判定，给聊天表情场景提供「尺寸/帧率/大小」傻瓜预设：
- 动图（GIF / WebP 动图 / APNG）→ 视频（发朋友圈、剪辑、投屏）
- 视频 → 动图（GIF / WebP 动图 / APNG，用于聊天表情包）
- 动图 → 动图（改尺寸/帧率/压缩，压小现成表情包）

## 范围
工具目录 `src/tools/sticker/`，id `sticker`，左侧名「动图与视频互转」，order 65，图标 🎞️。

- 方向判定（2026-09-18 实现时按「更傻瓜」调整，本节为准）：**逐条按文件类型处理，不再看第一个文件**——列表里动图与视频可以混着放：
  - 输出选了动图格式（GIF/WebP/APNG）时：视频 → 动图（生成动图）；动图 → 动图（改尺寸/帧率/压缩，用于压小表情包）；
  - 输出选了视频格式（MP4/WebM）时：动图 → 视频（H.264/VP9，动图无音轨故为无声）。
  - 界面上两块参数区（「转成动图」与「转成视频」）按所选输出格式自动显隐。
- **视频 → 动图**参数：
  - 起始时间（秒，默认 0）、时长（秒，默认 6，留空 = 全程）
  - 帧率：10 / 12 / **15（默认）** / 20 / 24
  - 宽度：240 / 320 / **480（默认）** / 720 / 保持原始
  - 输出格式：**GIF（默认）** / WebP 动图 / APNG
  - 循环：无限（默认）/ 播放一次
  - 目标大小：不限制（默认）/ ≤5MB / ≤2MB / ≤1MB；超出时自动降档（先降帧率 → 再降宽度 → GIF 再降色数），并在结果中注明实际档位
  - 一键预设：「聊天表情·标准」（240 宽 / 12 帧 / ≤5MB）、「聊天表情·压缩」（240 宽 / 10 帧 / ≤2MB）
- **动图 → 视频**参数：输出 MP4（默认）/ WebM；分辨率保持（默认）/ 1080p / 720p（只降不升）；可选截取（起始 + 时长，默认全程）；GIF 的透明背景自动铺白底。
- 保存：与原文件同目录（重名加序号），可用「设置 → 输出目录」覆盖。

## 非目标
- 不做表情包素材库/管理；不做逐帧编辑、加字、贴纸、变速。
- 不做微信/QQ 的「表情包格式包（.eif 等）」私有打包格式。

## 技术选型与依据
- 全部由 ffmpeg 完成（包内 6.1.1，已实测编码器/封装器齐备）：
  - 视频→GIF：两遍调色板 `split[a][b];[a]palettegen=stats_mode=diff[p];[b][p]paletteuse=dither=bayer:bayer_scale=5:diff_mode=rectangle`（业界常用的 GIF 质量方案）。
  - 视频→WebP 动图：`-c:v libwebp_anim -loop 0 -q:v 75 -compression_level 6`。
  - 视频→APNG：`-c:v apng -plays 0`。
  - 动图→视频：`-vf "scale=trunc(iw/2)*2:trunc(ih/2)*2,format=yuv420p"`（GIF 常为奇数边长，yuv420p 要求偶数）+ H.264/AAC 或 VP9/Opus。
  - 目标大小：按档位逐级重试（帧率 −2 帧、宽度 −20%、GIF 色数 256→128→64），最多若干轮，命中即停。
- 聊天表情的常见约束（240×240 附近、单文件几 MB 内）来自网络公开经验值，非平台官方承诺；预设文案不绑定具体平台名称。

## 已知限制
- 长视频转 GIF 即使压缩后仍可能较大；默认 6 秒 + 480 宽就是为此。
- GIF 最多 256 色，渐变会有轻微色带（bayer 抖动可缓解）。
- 透明动图 → MP4 会铺白底（H.264 不支持透明通道）。

## 验证结论（2026-09-18 实测回填）
- `--media-test`：MP4（3 s / 320×240）→ GIF（240 宽 / 12 帧 / 截取 1.5 s）62,980 B、时长 1.58 s；→ WebP 动图 22,208 B（容器校验 RIFF/WEBP + ANIM/ANMF 块 + 内核解码 240×180）；→ APNG 133,645 B；GIF（2 s / 160×120）→ MP4 9,050 B、时长 2 s。全部可解码/可渲染。
- `--media-ui-test`：动图与视频混合列表一次处理 6 项全部成功（GIF 输出），产物逐个 ffmpeg 解码通过；界面正确显示 ffmpeg 来源「加装包」。
- 实现期修正：APNG 输出必须显式 `-f apng`（按 `.png` 扩展名会被推断为单帧 image2，实测退出码 -22）；动图 WebP 的校验不能用 ffmpeg（其 webp 解复用器不认 ANIM/ANMF 动画块）。
- 目标大小自动降档（`sizeLadder`）已实现并接入界面，但本轮自动化没有覆盖「必须降档才能达标」的案例（测试片段本身较小，未触发降档）。
