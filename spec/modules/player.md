# 模块：视频播放器（player）

## 目标
在工具箱里直接播放视频：既能播本软件转出来的视频，也能播 MP4 / AVI / MKV / FLV 等常见格式；带播放/暂停、进度条、音量、全屏等基本控制；界面与工具箱风格一致；纯离线、无需另外安装任何播放器。
关键体验：**内核不支持的老格式自动转成可播放版本**（优先无损换封装，做不到才重编码），用户只需要点一次「打开视频」。

## 范围
工具目录 `src/tools/player/`，id `player`，左侧名「视频播放器」，**视频组内排最前（order 55）**，图标 ▶️。

- 输入：与其它视频工具一致的 15 种扩展名（VIDEO_EXTS：mp4/mov/mkv/avi/webm/flv/wmv/m4v/ts/3gp/mpg/mpeg/vob/rmvb/ogv）；对话框选择或直接拖进窗口。
- 播放内核：Electron 自带 Chromium 的 `<video>`（不额外引入播放器库、不带解码器二进制）。
- 本地文件访问：主进程注册的自定义协议 `tomato-media://`，**支持 HTTP Range**（边读边播、进度可任意拖动，GB 级视频不占内存）。
- 播放档位（`core/plan.js` 单一决策点，四档从轻到重，失败自动升档）：
  | 档位 | 触发条件 | 做法 | 代价 |
  |---|---|---|---|
  | direct | 容器 + 视频编码 + 音轨编码都被内核支持 | 直接播原文件 | 瞬时，零磁盘 |
  | remux | 编码都能播、只是容器不认（MKV/FLV/TS） | `-c:v copy -c:a copy` 换封装成 MP4 | 秒级 |
  | remux-audio | 画面能播、音轨进不了 MP4（AC3/WMA 等） | 画面直拷 + 音轨转 AAC | 秒级 |
  | transcode | 画面编码内核解不了（MPEG-4 ASP/WMV/RMVB 等） | libx264 CRF20 + AAC 192k → MP4 | 按时长，有进度、可取消 |
- 控制：播放/暂停、进度条（点击/拖动跳转、已播填充、时间显示）、音量（拖动 + 静音 + 音量为 0 自动显示静音）、全屏（双击画面或按钮进入，Esc/F 退出）。
- 快捷键（仅在本工具页显示且焦点不在输入框时生效）：空格播放/暂停、←/→ 前后 5 秒、↑/↓ 音量 ±5%、M 静音、F 全屏。
- 文案：文件信息行显示 `分辨率 ｜ 时长 ｜ 编码`；提示行说明「直接播放 / 无损换封装 / 已重编码」，让用户知道动没动过原文件。

## 非目标
- 不做播放列表、字幕、多音轨切换、画中画、倍速、硬件加速开关。
- 不做网络播放（http/rtsp/投屏）——本软件全离线。
- 不修改原视频；缓存副本只读播放、随时可删。

## 技术选型与依据
- **内核解码**（Electron 44 / Chromium 132+）能直接解：MP4/M4V/MOV/WebM 容器 + H.264/VP8/VP9/AV1/H.265（H.265 取决于系统解码器，失败会自动升档重编码）+ AAC/MP3/Opus/Vorbis/FLAC。
- **为什么不用 `file://`**：界面进程处于沙箱 + CSP（`default-src 'self'`），直接读本地文件被拦；自定义协议还能自己控制 Range 与 Content-Type。CSP 为此放行 `media-src 'self' blob: tomato-media:`（其它指令不变）。
- **为什么用 ffmpeg 而不是引入 mpv/VLC 之类内核**：ffmpeg 加装包已经随包分发（视频类工具必需），复用它=零新增体积；换内核要再加几十上百 MB，与本项目「解压即用 + 体积可控」冲突。
- 缓存目录 `userdata/player-cache/`（绿色版约定：只写软件目录，不碰系统 AppData）。副本名 = `原名-<源路径+档位+大小+修改时间的 sha1 前 10 位>.mp4`：同一文件重开直接命中缓存（秒开），源文件变了自动换新副本。
- 清理时机：进入工具页、换文件、离开工具页（含 LRU 回收）各清一次；被系统占用的副本留给下次清理，清理失败绝不影响播放。

## 已知限制
- 重编码档位要花时间（1080p 每分钟视频约数十秒，取决于 CPU）；界面有百分比与速度，并可取消。
- 只有长 5 秒以上的视频才适合拖动进度；超短片的进度条意义有限（不额外处理）。
- 缓存副本约等于源文件大小（换封装档位基本一致，重编码档位通常更小），切走工具页即释放，不会长期占地。
- H.265/HEVC 能不能直接播取决于系统解码器与显卡：能播就直接播，不能播会自动转 H.264（4K HEVC 长片重编码会比较慢）。
- ffmpeg 缺失时：原生格式（MP4/WebM/MOV）照常播放，其余格式给出「把加装包解压到 addons/ffmpeg」的放置说明，不静默失败。
