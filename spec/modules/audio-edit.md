# 模块：音频剪辑（audio-edit）

## 目标
把音频「剪开、拼起来、调响一点」：波形上拖出选区就能截，多个文件按顺序拼成一个，配上淡入淡出与音量调整。输出格式复用现有音频编码参数。

## 范围
工具目录 `src/tools/audio-edit/`，id `audio-edit`，左侧名「音频剪辑」，group `audio`，order 72，图标 ✂️。

- 批量导入：多选 / 拖拽文件 / 拖入文件夹；**也接受视频文件（自动取其中的音轨）**。
- **波形预览**：选中列表项即显示波形 canvas；可直接在波形上拖动选起点/终点，也可在时间框里输入（mm:ss.ms）。
- **截取**：起止时间可调；默认整段。
- **淡入 / 淡出**：档位 不做 / 0.5s / 1s / 2s / 3s。
- **音量**：不调整 / −6 dB / +3 dB / +6 dB / **音量标准化**（`loudnorm` 统一到 −16 LUFS）。
- **拼接**：勾选后按**列表顺序**把多个文件合并成一个输出。
- 输出格式：复用 `AUDIO_TARGETS` 的 21 种格式与 `AUDIO_QUALITY_PRESETS` 音质档，默认 MP3。
- 保存到原文件旁（重名自动加序号，不覆盖），可用「设置 → 输出目录」覆盖。
- 进度可取消；失败逐项标注并汇总。

## 关键技术决策
1. **波形不做全量解码**：一小时音频解成 Float32 约 600 MB，会直接爆内存。改为先用 ffmpeg 把音频**降采样成 8 kHz 单声道 WAV**（走共享层的 `transformImageBytes` 字节→字节通道），再解析峰值画图。**实际剪辑仍用原文件**，音质不受影响。
2. **无滤镜时走极速路径**：只截取、且不需要重编码时用 `-c:a copy`，几乎是瞬间完成（实测 6s 音频截 3s 仅 75 ms）。一旦带淡入淡出或音量滤镜就必须重编码，界面会提示这一差异。
3. **拼接用 concat 滤镜而非 concat 解复用器**：前者重编码但能容忍各段采样率/声道数不一致，对非技术用户更不容易翻车。为此主进程新增 IPC `ffmpeg:convert-multi`（多 `-i` + `filter_complex`），与单输入的 `ffmpeg:convert` 区分开。
4. **拼接模式下截取/滤镜不参与**：界面明确提示这一点，并且**在拼接时忽略这些参数**而不是静默出错（避免用户以为设了淡出却没生效）。

## 非目标
- 不做多轨混音、不做降噪/变调/变速、不做精确到采样点的剪切（毫秒级足够）。
- 不做波形编辑（删除区间、插入静音）——本期只做裁剪与拼接。

## 已知限制
- 单文件超过 30 分钟时给出明确提示（波形绘制会较慢，功能仍可用）。
- 拼接会重编码（不复制码流），因此拼接结果音质取决于所选输出格式与音质档。
- 输出格式与源格式不同时必然重编码，与是否使用滤镜无关。

## 依赖
- `shared/ffmpeg.js`（探测、单输入/多输入转码、进度、取消、`atrimArgs`/`audioFilterArgs`/`concatAudioArgs` 参数拼装）。
- 不依赖任何其它工具。
