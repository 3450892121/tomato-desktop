# 模块：批量与文件（batch）

## 目标
像手机版「全部」按钮那样，对多张图片批量做同一操作，并可靠落盘、给出汇总结果。

## 范围
- 导入：多选文件、拖入多个文件、拖入整个文件夹（递归取支持的图片格式）。
- 处理：对全部图片依次执行（模式 + 密钥统一）；显示总进度（第 n/N 张）。
- 保存命名（与手机版规则对齐）：`原文件名 + 混淆/解混淆 后缀 + 扩展名`；扩展名按 `imageio` 的格式规则（gilbert→.jpg，其余→.png）。
- 保存位置：默认输出到「原图所在目录」（可改，见 `settings`），重名自动加序号，不覆盖任何已有文件。
- 容错：单张失败不中断整批，结束后汇总「成功 N 张 / 失败 M 张」并列出失败原因。
- 全部还原 / 全部清除：只影响本次会话中已载入的图片（与手机版语义一致）。

## 输入 / 输出
- 输入：文件路径列表或文件夹路径、模式、密钥、操作类型（混淆/解混淆/还原/清除/保存）。
- 输出：磁盘上的结果文件、逐张状态与汇总信息。

## 非目标
- 不做任务队列持久化（关掉软件不保留未完成任务）、不做断点续传。

## 依赖的其他模块
- 依赖 `engine`、`imageio`、`settings`；被 `ui` 调用。
