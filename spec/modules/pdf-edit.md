# 模块：PDF 编辑整理（pdf-edit）

> 说明：本模块与 `pdf-convert.md`（转格式）互补——那个负责「转换」，这个负责「整理」。

## 目标
把 PDF 当文档来收拾：压小体积、加文字水印、加页码、旋转页面、重排页序、加/去打开密码。

## 范围
目录 `src/tools/pdf-edit/`，id `pdf-edit`，左侧名「PDF 编辑整理」，group `doc`，order 22，图标 📝。

七类操作（顶部下拉切换，参数区随类型变）：
1. **压缩瘦身**：四档 + 可勾「转黑白」+ 可选目标体积（设了目标则**不达标自动降档重试**）。
   - 原理：把每页渲染成位图后重新编码（JPG）再装箱——扫描件的体积几乎全是页面位图，只有重压位图才真正瘦身。
   - **必须提示**：原生文字版 PDF 会被转成图片，文字不再可搜索/复制（界面上有橙字警示）。
2. **文字水印**：文字/字号/透明度/旋转/颜色/位置（九宫格）/平铺；中文字体缺失时降级为标准字体并提示。
3. **页码**：格式支持 `{n}` 与 `{total}` 占位（如 `第 {n} 页 / 共 {total} 页`）、起始页号、位置、跳过首页。
4. **旋转页面**：按页范围旋转 90°/180°/270°（非法角度给出明确提示）。
5. **重排序**：按新页序数组重排（支持 `3,1,2` 与 `2-3,1` 两种写法，越界页号会报错）。
6. **加密**：设置打开密码 / 所有者密码 + 权限（打印/复制/修改）。
7. **解密**：输入密码后去掉加密（密码错误时明确提示）。

- 列表显示页数与体积；选中项可预览前若干页缩略图（页数多时分页看）。
- 输出到原文件旁（重名自动加序号），命名带操作后缀（`原名_压缩.pdf` 等），可用「设置 → 输出目录」覆盖。
- 批量、进度可取消、失败逐项标注。

## 关键技术决策
1. **用 `@cantoo/pdf-lib`**（pdf-lib 社区分支）：上游 pdf-lib **不支持加密**，本分支支持 `encrypt` 与 `TextRenderingMode`。
2. **中文字子集化必须配 `@cantoo/fontkit`**（不是 `@pdf-lib/fontkit`）：后者与本分支 API 不匹配，实测报 `Cannot read properties of undefined (reading 'pos')`（它只提供 v1 的 `encodeStream()`，而分支优先调 v2 的 `encode()`）。
3. **fontkit 在界面进程要走 UMD**：它的 ESM 产物里是裸模块名（`restructure` / `brotli` / `dfa` / `fflate`），本项目没有打包器，浏览器直接 import 会 `Failed to resolve module specifier`。故渲染进程用 `<script>` 加载 `fontkit.umd.min.js`（CSP `script-src 'self'` 允许同源脚本），Node 侧走 `import`。
4. **解密必须「搬家」而不是原地保存**：实测直接 `load(带密码) → save()` 会把 `/Encrypt` 原样写回，**输出仍打不开、等于没解密**。正确做法是把页面复制进一个**全新的 PDFDocument** 再保存（自检里加了 `/Encrypt` 字节检查作回归防线）。
5. 中文字体取自 `addons/ocr/fonts/NotoSansSC-VF.ttf`（与 OCR 工具共用一份，避免重复 17MB）；**取字走主进程 `ocr:font` IPC**——路径由主进程按 `PORTABLE_DIR` 解析，开发态与打包产物都正确；`import.meta.url` 相对路径仅作回退。相对深度只在开发态成立（产物上本文件在 `resources/app/src/...`，`addons/` 在产物根目录）——v2.11.1 之前只走相对路径，产物上字体读不到、中文水印/页码静默降级。

## 非目标
- 不做版面编辑（改文字、挪图片、加批注）——PDF 本身不存版面结构，这类需求不在本期。
- 不做电子签名/表单填写。
- 不做 PDF ↔ 图片/Office 转换（那是 `pdf-convert` 的事）。

## 已知限制
- 压缩会把页面栅格化：**原生文字版 PDF 压缩后文字变成图片**（不可搜、不可选），界面已明确警示。
- 压缩档位越低越糊；目标体积模式会依次降档，仍不达标就如实返回实际体积（不强求）。
- 加密使用 PDF 标准加密（RC4/AES 取决于库），不同阅读器对权限位的尊重程度不一。
- 中文字体缺失时，水印/页码只能用拉丁字符（降级为标准字体并提示）。

## 依赖
- `@cantoo/pdf-lib` + `@cantoo/fontkit`（子集化）；`shared/pdfops.js`（PDF 打开/渲染/压缩）；`jszip`（Word 导出，OCR 工具用）。
- 不依赖任何其它工具。
