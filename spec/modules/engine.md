# 模块：算法引擎（engine）

## 目标
在电脑上实现与手机版 APK 完全一致的 6 种像素重排算法（正向=混淆，反向=解混淆），对像素缓冲做可逆置换。

## 范围
- 6 种模式，内部标识与 APK 的 `algorithm_values` 一致：
  | 标识 | 界面名 | 密钥类型 | 算法要点 |
  |---|---|---|---|
  | `gilbert` | 空间曲线混淆 (番茄图) | 无 | Gilbert 空间填充曲线线性化 + 固定偏移 `round(N × 0.6180339887498949)` 的循环移位 |
  | `b` | 方块混淆 (B) | 字符串 | 32×32 方块级 MD5 洗牌；图先填充到 32 的整数倍 |
  | `c` | 像素混淆 (C) | 字符串 | 行、列双 MD5 错位表的两级像素错位 |
  | `c2` | 行像素混淆 (C2) | 字符串 | 仅行方向 MD5 错位 |
  | `pe1` | 兼容PE: 行模式 (PE1) | 0~1 小数 | Logistic 映射 `x→3.9999999·x·(1−x)` 排序错位表，逐行重排 |
  | `pe2` | 兼容PE: 行+列 (PE2) | 0~1 小数 | PE1 基础上加列方向，行/列序列链式衔接 |
- 字符串密钥洗牌：`MD5(密钥 + i)` 取前 7 位十六进制 → Fisher-Yates（i 从 N-1 递减到 1）。
- 密钥规则（与 APK 一致）：PE1/PE2 必须 `0 < 密钥 < 1`；B/C/C2 为任意字符串（可为空）；gilbert 无密钥。

## 输入 / 输出
- 输入：RGBA 像素缓冲（Uint8ClampedArray）、宽、高、密钥（按模式）、方向（混淆/解混淆）。
- 输出：同尺寸（方块模式为填充后尺寸）的新 RGBA 像素缓冲；不改动像素值，只重排位置。
- 纯函数、不碰文件系统、不依赖界面。

## 非目标
- 不发明新算法；不改变手机版的默认参数（32×32、3.9999999 等）。
- 不做像素值变换（加密/调色/水印）。

## 依赖的其他模块
- 无（独立实现）；被 `imageio`、`ui`、`batch` 调用。

## 待验证（未经证实）
- PE1/PE2 行/列序列的链式衔接细节（「逐块链式」vs「单一序列表」）需用手机版真机样本实测锁定；两种候选实现都预留可切换。
