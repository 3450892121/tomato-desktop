# 模块：图片变清晰（image-enhance）

## 目标
给发虚、发灰、有噪点、想放大的照片做一键增强：锐化、降噪、明暗对比微调、清晰放大 2 倍。

## 范围
工具目录 `src/tools/enhance/`，id `enhance`，左侧名「图片变清晰」，order 35，图标 ✨。

预设（单选）：
| 预设 | 参数 |
|---|---|
| 一键变清晰（默认） | 锐化 80% / 半径 1.2 / 阈值 2，对比度 +6% |
| 轻度锐化 | 锐化 40% |
| 强力锐化 | 锐化 140% |
| 照片降噪 + 轻锐化 | 降噪 50%，锐化 60% |
| 清晰放大 2× | 高质量重采样放大 2 倍 + 锐化 80%（只放大，不缩小） |
| **AI 放大 4×（照片，推荐）** | Real-ESRGAN `realesrgan-x4plus`，4 倍超分（加装包，需 Vulkan 显卡） |
| **AI 放大 2×（最快）** | Real-ESRGAN `realesr-animevideov3`，2 倍超分（速度最快） |
| **AI 放大 4×（动漫/插画）** | Real-ESRGAN `realesrgan-x4plus-anime`，4 倍超分 |
| 自定义 | 锐化强度 0~200%、半径 0.5~5、阈值 0~32、降噪 0~100%、亮度/对比度/饱和度 −100~100 |

- 预览：原图 / 处理后一键切换对比（适应窗口，不改变文件）。
- 批量：同一套参数应用到列表全部图片；逐张进度。
- 保存：保持原格式语义（JPG→JPG 画质 95；PNG→PNG；其它→PNG），命名 `<原名>_清晰.ext`，原目录旁（重名加序号）。

## 非目标
- 不做去模糊数学复原（对严重失焦无效，避免给用户过高预期）。
- 不做美颜 / 抠图 / 人像处理。

## AI 放大（超分）
- 形态：「图片变清晰」里的一组预设（AI 放大 4×（照片）/ 2×（最快）/ 4×（动漫插画）），选中后界面显示加装包状态与**硬件要求提示**。
- 实现：`addons/realesrgan/`（Real-ESRGAN v0.2.5.0 的 ncnn+Vulkan 便携版，exe + 模型约 50MB，BSD 3-Clause，随包分发）；
  主进程 `ai:upscale`：把图片先编码为 PNG 字节写临时文件 → 调 `realesrgan-ncnn-vulkan.exe -i in.png -o out.png -s N -n <模型>` → 读回字节（PNG）→ 用完即删临时目录。
- 输出规则：PNG 进 PNG 出；JPG 进 JPG 出（画质 95）；命名 `<原名>_AI放大.ext`。
- 预览：AI 每张要跑一次模型（秒级起），预览**不做** AI 处理，只显示原图并说明（避免误以为卡住）。
- **硬件要求（界面明确提示）**：需要支持 Vulkan 的显卡（近 8 年的独显与 Intel/AMD 核显基本都支持）；**纯 CPU 不可用**。
  不支持或驱动过旧时给出明确文案「本机显卡不支持 Vulkan（或驱动过旧），AI 放大用不了」，其它增强功能不受影响。
- 实测（本机，NVIDIA 显卡）：96×64 → 2× 1.6 秒；640×420 → 4×（2560×1680）5.5 秒；1280×720 → 4×（5120×2880）10.4 秒。

## 技术选型与依据
- 锐化：USM（Unsharp Mask）= 原图 + 强度 ×（原图 − 高斯模糊），阈值内像素不动以减少噪点放大；模糊用内核 `ctx.filter = blur(Npx)`（GPU 加速），差分与合成在 JS 逐像素完成（纯函数，可单测）。
- 降噪：轻度模糊与原图按强度混合（12MP 图上秒级内完成）；不做双边/非局部均值（成本高一个数量级）。
- 放大：`createImageBitmap(..., { resizeQuality: 'high' })` 重采样 + USM。

## 已知限制
- 锐化是「让边缘更分明」，不能恢复已丢失的细节（严重失焦、过度压缩的马赛克无法救回）。
- 「强力锐化」会放大噪点；噪点多的照片请用「照片降噪 + 轻锐化」。
- 放大 2× 不产生新细节，属于「更平滑的放大 + 锐化」。
