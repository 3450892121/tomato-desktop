# 模块：视频下载（videodl）

> 更新记录：v0.1（2026-09-26）新增模块（用户需求：把 `github.com/Lyee0011/leetools` 的 Windows 视频下载器集成进工具箱；经逐行拆读评估后按「引擎移植 + 界面重画」方案立项，上游自有代码为 MIT 许可）。

## 目标
粘贴视频链接，把网络视频下载到本地：抖音 / 小红书 / B站 / YouTube / 央视频 / yt-dlp 可解析的网站 + MP4 / M3U8 / MPD 直链。带进度、速度、剩余时间显示；可取消、可重试；下载完可一键在文件夹中定位；下载记录落盘保存（重启不丢）。
关键体验：**下载引擎（yt-dlp）可自更新**——网站改版导致解析失败时，用户点一下「更新引擎」就能恢复，不必等软件本体升级。

## 范围
工具目录 `src/tools/videodl/`，id `videodl`，左侧名「视频下载」，**视频组内排最前（order 54，下载是本组流程的入口；原排最前的播放器 55 顺延为第二位，其注释同步更新）**，图标 ⬇️。

- 输入：粘贴链接（回车或点「开始下载」）；保存目录可选（默认 `%USERPROFILE%\Downloads\视频素材`，复用现有选文件夹接口）；**单视频模式**，不做播放列表批量。
- 站点通道（全部实现在主进程，按上游能力移植）：
  | 通道 | 方式 |
  |---|---|
  | 通用站点（YouTube / B站 / yt-dlp 覆盖站点、MP4/M3U8/MPD 直链） | yt-dlp 下载 + ffmpeg 合并音视频并校验 |
  | B站增强 | 通用通道 + 上游插件（主 CDN 故障自动切备用线路；只读公开备用地址，不读登录态） |
  | 抖音 | 游客通道优先；受限时一次性匿名浏览器会话（全新临时目录，不读用户账号） |
  | 小红书 | 公开页面优先；受限时只读本机浏览器登录态（进程内使用，不导出 Cookie 文件） |
  | 央视频 | 上游独立解析模块（仅公开点播分享链接；播放地址过期自动重取一次并核对 MD5/大小） |
  | 其它动态网页 | yt-dlp 失败后用临时 Chrome/Edge 识别页面正在播放的公开资源（不接管已开浏览器、不点登录；一次一个、最多排队 3 个、约 22 秒超时） |
- 任务列表（工具页内）：进度条 / 百分比 / 速度 / 剩余时间 / 阶段（解析·下载·合并·校验）；失败给中文原因与「重试」；「清空记录」只清列表、**不删已下载文件**。任务同时登记进任务中心（通道 `io`），切走工具页任务照跑、进度可见。
- 取消：运行中任务可取消——终止下载进程并清理本次的半成品（`.part` / 临时目录），不留垃圾、不影响已完成文件。
- 校验与整理：下载后核对音视频流可解码（沿用上游 `inspectMedia`）；HLS 产物若实为 TS 则**无损换封装**为真 MP4（换封装成功才替换，失败保留原文件）；**不覆盖**已存在文件，重名自动加后缀；已存在且校验通过的文件如实提示「此前已下载过」。
- 历史：落盘在用户数据目录（重启不丢）；列表显示最近若干条（沿用上游上限：存 60、显示 30）。
- 引擎管理：工具页显示当前引擎版本与来源（随包版 / 已更新版）；「更新引擎」按钮 + 每周自动检查一次（可关）；更新包下载校验后放用户数据目录，**不动软件本体**；更新失败自动退回随包版，不阻塞下载。
- 代理：自动探测本机常见代理端口与 `HTTP_PROXY`/`HTTPS_PROXY`（大陆访问 YouTube 需要代理），界面显示探测结果。
- 合规边界：只下载公开可访问内容；不绕过付费、会员、DRM、验证码；失败提示如实分类（解析不支持 / 地区限制 / 需登录 / 网络错误）。

## 非目标
- 不做播放列表 / 合集批量、不做直播、不做字幕下载、不做清晰度选择 UI（取网站返回的最优公开档）。
- 不做账号登录，不导出 / 上传 Cookie，不处理人工验证码。
- 不做公网服务、不开监听端口——上游的 HTTP 服务层（会话令牌、Host/来源校验、端口管理）**不移植**，一律改走 Electron IPC。
- 不复刻上游「首次启动联网下载组件」流程（Node 用 Electron 内置、ffmpeg 复用现有加装包、yt-dlp 随包）。
- 不做内置浏览器播放页（下载完直接用本组「视频播放器」看）。

## 技术选型与依据
- **来源与许可**：`github.com/Lyee0011/leetools` 的 `video-downloader`（自有代码 MIT，已随代码附 License 文本与来源说明）。移植 = server.js 的引擎段（yt-dlp 任务 / 抖音 / 央视频 / 网页兜底 / 音画校验 / 防覆盖 / 代理探测）+ `scripts/` 全部模块 + B站 Python 插件；不移植 = HTTP 服务层、内嵌网页界面、PowerShell bootstrap 组件下载脚本。
- **yt-dlp 随包**：`addons/ytdlp/yt-dlp.exe`（上游锁定 nightly 2026.08.04.234419，SHA-256 按上游 `dependencies.windows.json`），许可按其第三方声明（源码 Unlicense / Windows 组合产物 GPLv3+）——与 ffmpeg 加装包同等待遇：随附许可文本 + 版本来源说明；B站插件放同目录 `plugins/`，以 `--plugin-dirs` 挂载。
- **ffmpeg 复用**软件现有 `addons/ffmpeg`（不再带第二份）。
- **运行时**：Electron 44（内置 Node ≥22），上游依赖的全局 `fetch` / `WebSocket` 均为内置，浏览器兜底模块零 polyfill；抖音匿名会话按上游方式以子进程运行（Electron 用 `child_process.fork`）。
- **引擎自更新**：查 GitHub 官方仓库最新 nightly release → 下载 → SHA-256 校验（取 GitHub API 的 asset digest）→ 落 `userdata/videodl-engine/`；运行期优先用更新版、否则用随包版；工具页不显示技术细节、只给「已是最新 / 已更新到 X」。
- **进度回传**：上游「浏览器轮询 `/api/jobs`」改为主进程主动推送（IPC 事件）；job 对象本身是纯数据，可直接沿用为传输结构。
- **设置**：保存目录、每周自动检查开关等存工具箱 settings（新增键进 `settings-schema` 校验，随「设置导入导出」一并生效）。

## 已知限制
- 网站改版会导致特定站点解析失败——此类工具的固有风险。缓解四件套：引擎自更新、错误提示引导「更新引擎」、交付前真实下载自检、定期同步上游 leetools 的适配修复（写进交付前检查清单）。
- 中国大陆下载 YouTube 通常需要可用代理；抖音 / 小红书兜底流程需要本机已装 Chrome 或 Edge（没有时常规通道不受影响）。
- 央视频仅支持公开点播分享链接；直播、试看、受保护格式不支持。
- 「支持更多网站」不等于「任意链接都能下载」：需登录、人工验证、付费、DRM、复杂嵌入播放器的仍可能失败（与上游行为一致，如实提示不假装成功）。
- 部分平台的使用条款可能限制下载行为——随包使用说明需写明「请只下载自己拥有权限或已获授权的内容」。
