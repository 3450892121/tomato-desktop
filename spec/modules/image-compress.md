# 模块：图片压缩（image-compress）

## 目标
批量把图片体积压小，尽量保住观感：拖进来、选档位、一键压，结果直接对比「原大小 → 新大小」。

## 范围
工具目录 `src/tools/compress/`，id `compress`，左侧名「图片压缩」，order 30，图标 🗜️。

- 批量导入：多选 / 拖拽文件 / 拖入文件夹（自动取其中支持的图片）。
- 输入格式：内核可解码的所有格式（PNG/JPG/WebP/BMP/GIF/ICO/AVIF）。
- 输出格式：自动（保持原格式语义：JPG→JPG、PNG→PNG、WebP→WebP，其它→JPG）/ JPG / WebP / PNG。
- 画质：JPG、WebP 提供 1~100 画质（默认 82）；PNG 无损无画质项。
- 尺寸：不缩放（默认）/ 最长边 N 像素（默认 1920）/ 按百分比。
- 压缩目标：画质优先（默认）/ 指定目标大小（KB，二分逼近画质；仍超标则按 √(目标/实得) 缩边后再试一轮）。
- 结果：每张显示原大小 → 新大小与降幅；汇总显示成功/失败数量与失败原因。
- 保存：与原图同目录（重名自动加序号，不覆盖），可用「设置 → 输出目录」覆盖。

## 非目标
- 不做 PNG 无损二次优化（内核不提供压缩级别控制）；PNG 想显著变小请选 WebP/JPG。
- 不做动图压缩（GIF / WebP 动图走「动图与视频互转」工具）。
- 不做图片编辑（裁剪/旋转/滤镜）——见「图片变清晰」工具。

## 技术选型与依据
- 解码 / 缩放 / 编码：复用 `shared/imageio.js`（Chromium 内核 `createImageBitmap` / `OffscreenCanvas`），零新增依赖；缩放用 `imageSmoothingQuality: 'high'`。
- 目标大小：对画质做二分（≤6 次编码），仍超标则按面积比缩边再二分（通用图片压缩实践，推断有效，实测回填）。

## 已知限制
- 重编码会剥离 EXIF / ICC 元数据（隐私更安全，但色彩可能轻微变化）。
- 超过 4000 万像素的图按 imageio 上限拒绝并提示。
- JPEG 体积还与画面内容强相关（纯色/复杂细节差异大），目标大小允许 ±15% 误差。
