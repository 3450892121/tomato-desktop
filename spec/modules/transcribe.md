# 模块：语音转文字（transcribe）

> 更新记录：v0.1（2026-09-19）新增模块（用户需求：「先把语音转文字做好」；语音生成/声音克隆方向经实测后由用户决定暂停，结论见会话记录）。

## 目标
把音频/视频里的说话内容识别成文字，批量、纯离线、傻瓜化；同时可产出字幕文件（SRT）供剪辑用。

## 范围
工具目录 `src/tools/transcribe/`，id `transcribe`，左侧名「语音转文字」，分组「音频」（audio），order 75，图标 🎙️。

- 输入：音频（mp3 / wav / flac / m4a / aac / ogg / opus / wma / ape / dsf 等一切 ffmpeg 可解格式）与视频（mp4 / mov / mkv / avi / webm / flv / wmv / m4v / ts / 3gp 等，自动提取音轨）；支持多选与整个文件夹。
- 输出三选一（下拉）：
  - 纯文本（`.txt`，默认）
  - 字幕（`.srt`）
  - 文本 + 字幕（同时产出两个文件，同一份识别结果，不重复跑模型）
- 保存位置：与原文件同目录（重名自动加序号，绝不覆盖）；可用「设置 → 输出目录」覆盖。
- 文件列表信息：时长 ｜ 格式 ｜ 大小；完成后显示「→ 输出文件名（字数）」。
- 批量、进度（按文件粒度 + 识别阶段）、可取消。

## 非目标
- 不做语音合成 / 声音克隆（用户 2026-09-19 决定暂停）。
- 不做实时/麦克风识别（仅文件）。
- 不做说话人分离（谁在说话）、不做翻译、不做说话人标注。
- 不提供语言选择：模型自动识别中/英/日/韩/粤（默认输出不带语言/情感标签）。

## 技术选型与依据（2026-09-19 实测）
- 内核：**FunASR llama.cpp/GGUF 运行时**（`llama-funasr-sensevoice.exe`）+ **SenseVoiceSmall q8**（242.4MB）+ **FSMN-VAD**（1.6MB），**MIT 许可、可商用**（运行时代码与模型同为 MIT，许可证全文随加装包分发）。随包分发为加装包 `addons/asr/`（不进 git，见 pack.js 步骤 5e）。
- 中文精度（官方 184 条中文测试集）：SenseVoice q8 CER **7.99%**，约为 whisper.cpp small（22.12%）的三分之一；本机 4 个真实样本叠加实测：与标准答案逐字一致（数字 ITN 例外，如「三点」→「3点」）。
- 速度（本机 i9-14900HX，纯 CPU）：6 秒音频端到端 0.64 秒（含模型加载）、18.9 秒音频 1.31 秒，约 **20 倍实时**；无需显卡。
- 输入统一处理：**一律先用 ffmpeg 转 16kHz 单声道 wav 再识别**。实测 exe 直读 wav/mp3/flac 可用，但 **m4a/ogg 会静默空输出**（退出码仍为 0），统一转码是唯一稳妥路径；视频顺带 `-vn` 提取音轨。ffmpeg 复用现有随包加装包。
- **调用 exe 必须传「相对 ASCII 路径」+ `cwd` 设为软件目录**：实测该 exe 收到含中文的 argv 路径会解析失败（`failed to open GGUF file`，与 sherpa CLI 同类编码问题）；cwd 由系统按 Unicode 解析不受影响。工作目录固定放在 `软件目录/userdata/tmp/`（随用随清 + 24 小时遗留清理），保证模型与音频路径全程 ASCII。
- 输出：exe 原生 `--srt` 产出标准 SRT（实测含 `序号/时间戳/文本` 三段式）；纯文本由 SRT 去除序号与时间戳推导（同一份识别结果）。
- 加装包缺失时显示「未检测到语音识别加装包」与放置说明，不静默失败。

## 已知限制
- 输出为「顺滑文本」，标点由模型自带，不做二次校对；数字为阿拉伯数字形式（模型 ITN 行为）。
- 长音频按 VAD 分段：SRT 每段一条；纯文本按段换行。
- 无语音/纯音乐输入会得到空结果：按「未识别到语音内容」提示并计入失败项，不产出空文件。
- 需要 ffmpeg 做输入预转码（随包自带；缺失时按 ffmpeg 加装提示处理）。

## 验证结论（2026-09-19 实测回填）
- `--asr-test`：**ok:true**。计划逻辑单测（SRT→文本、SRT 合法性、输出模式、文案函数）通过；SAPI 离线合成中文语音夹具 → 真实识别「今天下午3点开会，请大家准时参加。」（关键词 3/3 命中）；`.txt` 落盘内容与返回一致且无时间戳、`.srt` 含时间戳；视频（5 秒 mp4）走「提取音轨 → 识别」通过；无效文件（文本冒充 wav）报错且不产出文件。
- `--asr-ui-test`：**pass:true**。连续两轮（文本+字幕 → 纯文本）：第一轮 4 个产物（2 txt + 2 srt，含视频文件），第二轮 2 个 txt 重名自动加序号（`(1)` 后缀，不覆盖）；含视频文件正确标注「视频（提取声音）」；清空生效；5 张截图。
