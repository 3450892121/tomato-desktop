# 软件卸载（工具：`uninstall`）

> 范围：把随包内置的卸载工具从软件内一键拉起（管理员权限），连同残留一起清掉。
> 关键前置结论（已与用户确认，三问三答）：
> 1. **随包内置 HiBit 便携版**（`app/addons/hibit/`）+ 新增「软件卸载」工具页——用户不用自己装 HiBit，免安装包发给别人也能直接用。
> 2. **以管理员身份启动**（点按钮时由系统弹一次 UAC 确认框）——卸载与清理注册表需要管理员权限，且官方 exe 的清单（manifest）里写的就是 `requireAdministrator`，不提权根本起不来。
> 3. **工具页做「极简启动页」**——一个启动按钮 + 用法说明 + 版本/来源信息；本期不做原生「已安装程序列表」。

## 目标
在工具箱里提供一个「软件卸载」工具：一键启动随包内置的 HiBit Uninstaller（管理员权限），把「卸载软件 + 清理残留」这件事
收进本软件，用户不必自己去找、去装第三方卸载工具；界面形态与本工具箱其余工具一致（同主题、同组件、同交互约定）。

## 范围

### 引擎（加装包，随主包分发）
| 项 | 值 |
|---|---|
| 位置 | `软件目录/addons/hibit/HiBitUninstaller-Portable.exe`（见 pack.js 步骤 5h） |
| 版本 | 4.0.10（Windows x64，单文件便携版，约 15.4 MB；版本号另存 `addons/hibit/版本.txt`，供界面显示） |
| 来源 | 官方站 https://www.hibitsoft.ir/Uninstaller.html 的 Portable 包（未做任何修改、不重命名） |
| 许可 | 官网标注「个人与商业使用均免费」；**未找到关于「再分发」的明文条款**（诚实标注，见「选型依据」） |
| 运行要求 | 管理员权限（清单 `requireAdministrator`）；Windows Vista~11 |

- 缺失时：工具页显示「未检测到软件卸载加装包」+ 放置说明（与 ffmpeg / 7zip / ocr 等既有加装包同一约定），**软件不崩、其余工具不受影响**。
- 加装包目录**不进 git**（`.gitignore` 的 `app/addons`），由 `pack.js` 步骤 5h 随主包复制。

### 交互（极简启动页）
1. 工具页显示：标题说明、**「打开卸载工具（管理员）」主按钮**、用法要点（怎么卸载、什么是残留扫描）、引擎状态卡（版本 / 来源 / 是否就绪）。
2. 点按钮 → 主进程以 `RunAs` 拉起 HiBit（系统弹 UAC）→ 状态栏如实反馈三种结果：已启动（请在 UAC 里点「是」）/ 用户取消了授权 / 启动失败（附原因）。
3. 未检测到加装包时按钮禁用，状态卡给出放置说明。
4. 页面为纯启动页：无文件列表、无任务队列接入、无进度遮罩（单次秒级动作）。

### 提权实现（唯一路径）
- 渲染进程只发 `hibit:launch`；主进程用**绝对路径**的 Windows PowerShell（`%SystemRoot%\System32\WindowsPowerShell\v1.0\powershell.exe`）
  执行 `Start-Process -FilePath <exe> -WorkingDirectory <dir> -Verb RunAs`——Electron 自身没有提权 API，这是 Windows 上的标准做法。
- **不静默提权**：只有用户点按钮才发起；UAC 由系统把关，软件不缓存/不代填任何凭据。
- 用户取消 UAC（PowerShell 报 `The operation was canceled by the user`）→ 返回 `{ ok:false, canceled:true }`，界面提示「已取消管理员授权」，不当作错误刷屏。
- 开发/自动化测试（`testMode()`）下 `hibit:launch` **一律不真的拉起进程**（否则会弹 UAC 卡住测试），返回 `{ ok:true, dryRun:true }`。

### 分组
左侧新增「系统」分组（`GROUPS` 增加 `{ id:'system', name:'系统', icon:'🧰' }`），本工具 `group: 'system'`、`order: 10`。
理由：既不属于图片/视频/音频/文档/压缩，收入「其它」不好找；后续系统类工具（清理、启动项…）也可归此组。

## 非目标（本期明确不做）
- **不做原生卸载列表**（自己读注册表列已安装程序、自己调卸载程序）——用户已选定「极简启动页」；HiBit 的残留扫描、强制卸载、批量卸载、Store 应用管理等能力不在本软件内重复实现。
- **不修改 HiBit 本体**（不改名、不裁剪、不注入、不打包成我们自己的界面）；不做「把外部窗口嵌进工具页」——Electron 无法稳定内嵌第三方 Win32 GUI，硬嵌属于高风险花活。
- 不做安装/更新 HiBit（不加更新检查——本项目全离线）。
- 不做联网（无云查毒、无上报、无「软件库」）。
- 不代管 HiBit 自身的设置（它自己的数据目录由它自己决定，见下）。

## 选型依据（为什么是 HiBit 便携版）
| 方案 | 结论 |
|---|---|
| **HiBit Uninstaller 便携版（选用）** | 单文件免安装、纯本地、个人与商业使用均免费、无内置广告与「专业版」阉割；能力覆盖卸载 + 残留扫描 + 强制卸载 + 批量卸载 + Store 应用，且有官方中文界面 |
| 自研原生卸载 | 体积最小，但要把「强制卸载 / 残留扫描 / 注册表清理」做到可比水平工作量极大，且误删风险高——**用户已否掉** |
| 只做启动页、调用系统已装的 HiBit | 体积 0，但别人拿到免安装包会打不开（对方电脑没装）——**用户已否掉** |
| Revo / Geek Uninstaller 等替代 | 功能相近，但便携版许可、体积与中文支持均不优于 HiBit；无更换理由 |

**许可与分发的诚实说明**：官网首页标注「个人与商业使用均免费（Free for personal and commercial use）」，未另见明文「可再分发」条款。
本项目的做法是：① 使用官方原版文件、**不做任何修改与改名**；② 加装包目录内附 `说明.txt`（版本、来源链接、许可说明）；
③ 规格与 README 如实写明来源。若权利人另有要求，删除 `addons/hibit/` 即整体下线，软件其余部分不受影响。

## 安全与红线
- 软件自身**不写系统 AppData**（绿色版约定照旧）；HiBit 作为独立程序，其设置位置由它自己决定，本软件不代管、不读取。
- 不静默提权、不绕过 UAC；不传任何参数给 HiBit（不给它喂「自动卸载某某」这类无人值守指令）——**卸载什么由用户在 HiBit 界面里自己点**。
- 自动化测试模式下绝不真的启动（避免无人值守时弹 UAC、甚至真的执行卸载动作）。
