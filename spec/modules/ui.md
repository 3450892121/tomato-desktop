# 模块：界面交互（ui）

## 目标
做出**清爽浅色现代风**的傻瓜化界面：身边人拿到就能看懂、会用，布局参考手机版但更适合鼠标与键盘。

## 范围
- 布局（参考手机版结构，桌面化改良）：
  - 顶部：状态提示条（当前操作结果/提示）+ 参数信息（分辨率、处理耗时）。
  - 中部：大图预览区（未选图时居中显示「添加图片（可选多张）」大按钮）。
  - 预览区上方：模式下拉框（6 项，文案与手机版一致）、密钥输入框（按模式自动切换：字符串 / 0~1 小数 / 无密钥时整行隐藏）、「帮助」入口。
  - 底部第一排（当前图）：混淆 / 解混淆 / 清除 / 还原 / 保存。
  - 底部第二排（全部图）：全部混淆 / 全部解混淆 / 全部清除 / 全部还原 / 全部保存（与手机版「全部」按钮对应）。
  - 缩略图条：多图时显示，点击切换当前图，悬停显示「详情/打开方式/分享/移除」入口（对应手机版长按菜单）。
- 交互：拖拽图片进窗口打开；从剪贴板粘贴图片；结果可复制到剪贴板或另存。
- 视觉规范：全部颜色/字号/间距/圆角/动效节奏集中在 `theme.css` 的 CSS 变量（一处修改全局生效）；组件复用（按钮、卡片、缩略图只写一份样式）。
- 内置帮助：图文说明每种模式、密钥规则、兼容性注意事项（图片尺寸保持一致等）。

## 输入 / 输出
- 输入：用户操作事件、处理进度、错误信息。
- 输出：调用 `engine`/`imageio`/`batch` 的指令；界面状态更新。

## 非目标
- 本期不做深色主题、不做多语言、不做自定义皮肤。

## 依赖的其他模块
- 依赖 `engine`（模式列表与密钥规则）、`imageio`（预览与保存）、`batch`（全部按钮）、`settings`（默认参数）。

## 工具导航（v1.1 新增，配合 toolkit）
- 主界面为左右两栏：**左侧工具列表**（图标 + 名称，当前工具高亮）+ 右侧当前工具界面。
- 工具列表由 `shell/registry.js` 自动渲染，新增工具无需改界面代码。
- 切换工具时（v1.8.0 起）：把上一个工具页从文档取下（保留在内存，不销毁、不重新挂载；**v2.1.1 起若它「没动过」则直接释放**）→ 加载新工具样式 → 首次进入时挂载其界面 → 页面带轻微上浮淡入切回。
  切回原页面时，列表/当前项/输入/滚动位置与顶栏提示全部保留（详见 `toolkit` 的「工具页保活」，及其中「动过才算」的额度规则）。
- 左侧列表底部固定放「设置」（通用参数）与「帮助」入口（不随工具变化）。
- **切换工具不重建左侧列表**（v2.1.0 修复）：只在启动 / 设置变化时 `renderNav()`；切换工具时只挪 `is-active` 高亮，并「瞬时」展开当前工具所在分组。
  修复前的 bug：`switchTool` 每次都重建整列，重建瞬间按用户偏好渲染成收起、紧接着又自动展开，用户看到的是「子项先折叠再打开 + 整列闪烁」。

## 组件库与动效（v1.8.0 新增，用户要求）
- 通用组件集中到 `shell/components.css`（唯一来源）：按钮、输入框 / 下拉框、卡片、弹窗、进度遮罩、表单字段、帮助排版；工具只写自己的 `styles.css`。
- 动效节奏集中在 `theme.css`：`--transition-fast / base / slow / collapse` + `--ease-out`，禁止在组件里写死时间。
- 动效清单（全部与主题风格一致、不花哨）：
  - 页面切换：`page-in`（8px 上浮 + 淡入，260ms）；
  - 侧栏分组收起/展开：高度 + 透明度过渡（220ms，具体高度由 shell.js 量出，任何行数都自然）；
  - 弹窗：打开「遮罩淡入 + 卡片轻微放大上浮」，关闭先淡出再移除；
  - 按钮：纯色按钮悬停轻微上浮 + 阴影加深、按下回弹；`focus-visible` 有键盘聚焦环；
  - 当前工具：左侧导航项带一条会「长出来」的红色标记条。
- 无障碍：尊重系统「减少动态效果」（`prefers-reduced-motion: reduce` 时动效降为瞬时），收起的分组对键盘不可见（`visibility: hidden`）。

## 玻璃质感与选中反馈（v2.1.0 新增，用户要求）
- 用户诉求原话：「加一个苹果那种玻璃效果」「动效明显一点，要不然我都发现不了我选中了」。
- **磨砂玻璃（Apple 风）**：窗口背景 → 侧栏 / 顶栏 / 卡片 / 弹窗 / 任务抽屉 / 进度遮罩，统一做成玻璃面。
  - 组成：半透明玻璃底 + `backdrop-filter: blur() saturate()` + 高光边（1px 亮边）+ 内高光（顶部 1px 白线）。
  - 令牌集中在 `theme.css`：`--glass-blur / --glass-saturate / --glass-bg / --glass-bg-strong / --glass-bg-soft / --glass-border / --glass-inner-highlight / --glass-sheen`，深色主题只覆盖同名变量。
  - **看得见才算数（用户二次反馈「几乎感知不到」后的硬指标）**：玻璃面必须够透（alpha ≤ 0.55）、模糊够大（≥30px）、并带斜向高光（`--glass-sheen`）；侧栏 / 卡片与背景之间必须有肉眼可辨的明度或色相差异，验收时以截图为准。
  - 表面色令牌（`--color-surface` / `--color-surface-soft` / `--color-sidebar-bg`）改为半透明玻璃值，工具按约定引用即自动玻璃化，工具代码零改动。
- **背景光晕**：玻璃要「有东西可糊」才看得出磨砂，所以窗口背景铺一层暖色光晕（浅色/深色各一套，`--bg-aurora-*`）。
  - 强度：不透明度 ≤ 0.35（v2.1.0 二次调强，原 0.2 太淡、玻璃看不出来）；且不改 `--color-bg` 底色值（窗口底色与 `main.js` 的 `windowBackgroundColor` 保持一致，避免启动闪白）。
  - 约束：光晕只影响观感，不得压过内容——文字对比度仍需可读，图片预览区不参与（图片本身是不透明画布）。
- **选中反馈统一为「一眼能看出」**：
  - 令牌：`--color-select-bg`（实心染色块）/ `--color-select-border` / `--color-select-ring` / `--shadow-select`（外发光环 + 投影）。
  - 侧栏当前工具：染色块 + 主色描边环 + 加粗标记条（更粗更长）+ 切换时弹簧放大（`select-pop`）。
  - 工具内选中项（缩略图 / 列表项 / 分段按钮）：统一改为染色块 + 描边环 + 投影，缩略图额外轻微放大上浮。
- **动效整体调强一档**：`--transition-*` 时长加长，新增回弹曲线 `--ease-spring` / `--transition-spring`；仅用于「选中、切换、浮层」，不改变功能按钮的克制手感。
- 非目标：不做真·无边框窗口 / 系统亚克力材质（Mica/Acrylic）、不做逐工具换肤、不动内容画布（图片预览、PDF 画布、Office 预览仍按原始颜色呈现）。
