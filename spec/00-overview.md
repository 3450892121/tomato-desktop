## 项目定位
把安卓 App「番茄图片混淆」（`番茄图片混淆.apk`）的图片混淆/解混淆能力完整搬到 Windows 电脑上，做成**解压即用的免安装绿色软件**：纯离线、与手机版互相兼容。
软件按**工具箱**形态搭建：左侧列出所有工具，右侧是当前工具的界面；「图片混淆」是第一个工具，后续（图片压缩、PDF 转格式、视频提取等）按同一套模板低成本接入。

## 目标用户
- 主要使用者：作者身边的朋友/同事（非技术用户，需要傻瓜化操作与内置说明）。
- 使用场景：在电脑上对图片做混淆（打乱像素，防内容被直接识别）与解混淆（还原原图）；后续扩展为常用文件处理工具箱。

## 总体边界
**做什么（本期）**
1. 工具箱框架：左侧工具列表 + 工具切换 + 工具注册机制 + 新工具模板与说明。
2. 第一个工具「图片混淆」做完整：6 种混淆/解混淆模式，规则与手机版 APK 完全一致：空间曲线(番茄图 gilbert)、方块混淆(B)、像素混淆(C)、行像素混淆(C2)、兼容PE 行模式(PE1)、兼容PE 行+列(PE2)。
3. 单张处理 + 批量处理（多文件/整个文件夹）。
4. 拖拽图片进窗口、从剪贴板粘贴图片、复制/另存结果。
5. 可调高级参数：方块数（默认 32×32）、JPG 画质（默认 95）、默认密钥（默认 0.666）等。
6. 内置图文帮助（说明每种模式、密钥规则、兼容性注意事项）。
7. 与手机版互相兼容：电脑混淆的图手机能解、手机混淆的图电脑能解（以真机实测验收）。

**明确不做什么（本期）**
1. 不做任何联网功能（无更新检查、无云同步、无账号）。
2. 不做手机端 App。
3. 不做与混淆无关的图片编辑（裁剪、滤镜、格式转换、压缩等）——这些属于未来的新工具，本期只预留位置与接入模板，不实现。
4. 图片压缩、视频提取等具体新工具仍不在本期；「PDF 转格式」已单独立项（见 `modules/pdf-convert.md`，按用户选定范围设计），其余新工具按模板低成本加入。
   - 注（v1.3 起）：本条对「本期 = v1.0」有效；图片压缩、图片变清晰、图片格式转换、视频格式转换、动图与视频互转已按用户 2026-09-18 新需求立项并实现，见对应 modules 文件。
5. 不改动手机版既有算法与默认参数（只做「相同规则」的实现与可调覆盖）。

## 代码结构约定（新增工具时只动 tools/ 与 registry 一行）
```
app/src/
├─ shell/            框架：页面、左侧导航、工具注册表、设计令牌、通用组件
├─ tools/            一个工具一个文件夹（自包含：声明 + 界面 + 逻辑 + 样式）
│  ├─ obfuscate/     图片混淆（本期完整实现）
│  ├─ pdf-convert/   PDF 转格式（第二个工具，见 modules/pdf-convert.md）
│  └─ _template/     新工具空白模板（复制改名即可）
└─ shared/           跨工具复用：图片读写、文件封装、设置读写
```
- 工具之间不互相依赖；要复用的能力一律放 `shared/`。
- 新增工具 = 复制 `_template` 文件夹改名 + 在 `shell/registry.js` 加一行；不改任何既有工具代码。

## 技术栈与运行环境
- Electron（自带内核的桌面框架）+ 原生 HTML/CSS/JS；不引入重型第三方依赖（PDF 工具使用纯 JS 的 pdfjs-dist / pdf-lib，仍属轻量；LibreOffice 仅作为可选加装包，不进主安装包）。
- 注（v1.3 起）：视频类工具随包分发 **ffmpeg 6.1.1 静态构建**（单文件 82.8 MB，GPL v3，来源与许可见 `addons/ffmpeg/说明.txt`）——这是「解压即用」的必要代价；无 ffmpeg 时其余工具不受影响。
- 目标系统：Windows 10/11 64 位。
- 交付形态：解压即用的绿色文件夹；版本起点 v1.0.0。

## 关键事实来源
- `番茄图片混淆.apk` 反编译分析结论（函数签名、模式映射、密钥规则、保存格式、填充规则）。
- 生态参考实现（交叉印证）：网页版「小番茄」JS 实现（gilbert）、`pyscramble`（Rust，MIT）、`PicEncrypt`（PE1/PE2 出处，开源）。
- 未证实项：PE1/PE2 native 内部「链式细节」存在两种候选实现，须用手机版真机样本实测锁定（见 `acceptance.md` A2）。
