# 00-overview — 番茄图片混淆 桌面版

## 项目定位
把安卓 App「番茄图片混淆」（`番茄图片混淆.apk`）的图片混淆/解混淆能力完整搬到 Windows 电脑上，做成**解压即用的免安装绿色软件**：纯离线、与手机版互相兼容。

## 目标用户
- 主要使用者：作者身边的朋友/同事（非技术用户，需要傻瓜化操作与内置说明）。
- 使用场景：在电脑上对图片做混淆（打乱像素，防内容被直接识别）与解混淆（还原原图）。

## 总体边界
**做什么（本期）**
1. 6 种混淆/解混淆模式，规则与手机版 APK 完全一致：空间曲线(番茄图 gilbert)、方块混淆(B)、像素混淆(C)、行像素混淆(C2)、兼容PE 行模式(PE1)、兼容PE 行+列(PE2)。
2. 单张处理 + 批量处理（多文件/整个文件夹）。
3. 拖拽图片进窗口、从剪贴板粘贴图片、复制/另存结果。
4. 可调高级参数：方块数（默认 32×32）、JPG 画质（默认 95）、默认密钥（默认 0.666）等。
5. 内置图文帮助（说明每种模式、密钥规则、兼容性注意事项）。
6. 与手机版互相兼容：电脑混淆的图手机能解、手机混淆的图电脑能解（以真机实测验收）。

**明确不做什么（本期）**
1. 不做任何联网功能（无更新检查、无云同步、无账号）。
2. 不做手机端 App。
3. 不做与混淆无关的图片编辑（裁剪、滤镜、格式转换、压缩等）。
4. 不改动手机版既有算法与默认参数（只做「相同规则」的实现与可调覆盖）。

## 模块划分（与 modules/ 一一对应）
| 模块 | 文件 | 一句话职责 |
|---|---|---|
| 算法引擎 | `modules/engine.md` | 6 种模式的正/反向像素重排，密钥解析 |
| 图片读写 | `modules/imageio.md` | 解码/编码图片、填充与格式规则（gilbert→JPG q95，其余→PNG） |
| 界面交互 | `modules/ui.md` | 浅色现代风界面、预览、拖拽、剪贴板、进度 |
| 批量与文件 | `modules/batch.md` | 多文件/文件夹导入、批量处理与保存命名 |
| 参数设置 | `modules/settings.md` | 可调参数与本地持久化 |

## 技术栈与运行环境
- Electron（自带内核的桌面框架）+ 原生 HTML/CSS/JS；不引入重型第三方依赖。
- 目标系统：Windows 10/11 64 位。
- 交付形态：解压即用的绿色文件夹；版本起点 v1.0.0。

## 关键事实来源
- `番茄图片混淆.apk` 反编译分析结论（函数签名、模式映射、密钥规则、保存格式、填充规则）。
- 生态参考实现（交叉印证）：网页版「小番茄」JS 实现（gilbert）、`pyscramble`（Rust，MIT）、`PicEncrypt`（PE1/PE2 出处，开源）。
- 未证实项：PE1/PE2 native 内部「链式细节」存在两种候选实现，须用手机版真机样本实测锁定（见 `acceptance.md` A2）。
