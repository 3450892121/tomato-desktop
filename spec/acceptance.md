# 验收标准（acceptance）

> 规则：每条必须**可量化、能对照**；交付时**必须附测试证据**（脚本输出/比对数据/截图）。
> 关键项（A2）由用户真机执行，开发方不得自证。

## A1 算法往返正确性（自动比对）
测试图 3 张：①宽高非 32 倍数的常规照片；②带透明通道 PNG；③小尺寸纯色图（如 37×19）。
- 6 种模式分别执行「内存内混淆 → 解混淆」，输出与输入**逐像素 100% 一致**，6/6 通过（以 PNG 无损路径比对）。
- 方块模式对 ① 的填充结果尺寸为 32 的整数倍，且仍能 100% 解回原图区域。
- 证据：比对脚本输出（逐字节 diff 为 0 的日志）。

## A2 与手机版互相兼容（真机实测，关键项）
样本：每模式各 1 张（源图用 PNG 截图类图片）。
- 手机版混淆 → 电脑版解混淆：6/6 与原始图**逐像素 100% 一致**（若手机版存 JPG 则按 PSNR ≥ 40dB 判定）。
- 电脑版混淆 → 手机版解混淆：6/6 还原成功（人工确认，附前后截图）。
- 证据：样本文件 + 比对脚本输出 + 手机截图（≥6 张）。
- 说明：PE1/PE2 若首次不一致，用样本定位并修正链式实现后重测，直到 6/6 通过。

## A3 尺寸与保存格式规则
- `b` 模式：100×50 输入 → 128×64 输出（填充到 32 倍数，不裁剪）。
- `gilbert`：保存为 `.jpg`，画质参数 95；`c/c2/pe1/pe2` 保存为 `.png`，尺寸与输入一致。
- 证据：文件列表 + 文件头/尺寸读取输出。

## A4 批量与容错
- 一次导入 ≥20 张（其中 1 张故意损坏/非图片）：整批完成，损坏项被跳过并计入失败汇总，其余全部成功且可解回。
- 输出文件命名符合「原文件名+混淆/解混淆后缀」，不覆盖已有文件（重名自动加序号）。
- 证据：批量结果目录截图 + 汇总信息截图。

## A5 交互能力
- 拖入 1 个文件夹 → 自动载入其中所有支持的图片。
- 剪贴板粘贴 1 张图 → 可处理并复制结果回剪贴板。
- 模式切换时密钥输入框自动切换为「字符串 / 0~1 小数 / 隐藏」三态（gilbert 隐藏）。
- 证据：操作录屏或逐项截图。

## A26 保活页 LRU 回收（v1.9.0；v2.1.1 起额度只按「动过」的页算）
- 保活的**「动过」页**最多 5 个（含当前页），超出时淘汰最久没用过的那一页：该页被 `unmount` 并丢弃，下次进入重新挂载（内容从头开始）。
- 「动过」＝在这一页里点按 / 打字 / 拖入过文件（`pointerdown / click / keydown / input / change / drop / paste`）；只是点开看看（含滚动）不算——
  **没动过的页不占额度、切走即静默释放，绝不因此挤掉别处用过的东西**（用户反馈：「随便看看」不能清空前面的使用记录）。
- 当前页永不被回收；「动过」的页被回收后再次进入时，状态栏提示「（用过的工具较多，上次的内容已自动释放）」。
- 切换页数在上限内时（如只切了 1 个工具）状态仍完整保留，不受回收影响。
- 证据：界面自动测试 `checks.browseKeepsState`（载入图片 → 纯浏览一圈 5 个工具 → 切回：列表张数原样、状态栏无「自动释放」）
  + `checks.lruRelease`（在这 5 个工具里各动一下 → 切回：列表已清空、按钮回到初始态、状态栏含「自动释放」）
  + 截图 `shot-12a-纯浏览后状态仍在`、`shot-12-LRU回收后`。

## A28 OCR 引擎可用性闸门（P0，v1.10.0 起）
- 在正式开发「文字识别」工具前，必须先证明 OCR 引擎能在本软件内**纯离线**跑通中文扫描件。
- 判据：3 张自造夹具（干净白底 / 灰底噪声 / 轻微倾斜）中至少 2 张中文**字符召回 ≥ 80%**；单张 ≤ 8 秒；全程**0 次网络请求**。
- 实测结果：3/3 召回 100%，单张 281~570 ms，引擎初始化 275 ms，`fetchCalls = 0`。
- 技术结论：引擎 `ppu-paddle-ocr`（MIT）+ 本地 PP-OCRv5 mobile ONNX 模型（`app/addons/ocr/`，约 20MB）+ `onnxruntime-node`（N-API，ABI 稳定），**运行在主进程**——主进程无 CSP 限制，无需为 WASM 放宽 `script-src`/`worker-src`，也无需 blob URL 搬运模型。
- 证据：`--ocr-poc` 输出 `OCR_POC {..., "ok":true}`，结果落盘 `%TEMP%/tomato-ocr-poc.json`。

- **缺包降级**：隐藏 `addons/ytdlp` 且无更新版引擎时，工具给出放置说明与「检查更新」，软件不崩、其余工具不受影响。
- **网络判定**：无网络环境下，联网用例如实记 `skipped` 且整体 `verified:false`（**不得当通过**）；交付前必须在有网环境跑到 `verified:true`。
- 证据：`--videodl-test`（`%TEMP%\tomato-videodl-test.json`）+ `--videodl-ui-test`（`%TEMP%\tomato-videodl-ui-test.json`）+ 截图 `shot-videodl-*.png` + 上游 MIT 许可文本随代码在位的清单。

## A44 Agent 入口（MCP，v2.14.0 起；v2.14.1 安全加固；当前开发线增加 Qoder 一键接入 + 接入体检）
- **本地 stdio MCP**：`app/mcp/server.mjs` 能完成 `initialize` / `tools/list` / `tools/call`；41 个工具注册，覆盖 21 个 GUI 工具；**不暴露**视频播放器与软件卸载。
- **四批能力**：纯 Node（混淆/藏图/压缩/PDF 组装/重命名）、媒体与本地 AI（ffmpeg/OCR/ASR/PDF 编辑）、Canvas 类（压缩/增强/转换/水印/拼接/切图）、文档与下载（PDF→图片/压缩、Office→PDF、PDF→Word、doc_convert、可搜索 PDF、AI 放大）。
- **视频下载授权**：默认每次询问；无授权时 `video_download` 返回 `NEEDS_APPROVAL` 且零下载；GUI 开「本次运行有效」或「允许一次」后，MCP 能真实下载；授权文件只由 GUI 写、MCP 只读；软件退出清空 session。
- **路径白名单**：默认只允许用户目录/系统临时目录/软件目录；`TOMATO_MCP_ALLOWED_ROOTS` 可显式放宽；白名单外的读写被拒绝。
- **不覆盖**：产物重名加序号；`archive_extract` 拒绝 `overwrite:"replace"`，`file_rename_batch` 拒绝 `conflict:"overwrite"`。
- **只读模式**：`TOMATO_MCP_READONLY=1` 时只暴露只读工具，写工具被拒。
- **审计日志**：每次调用写 `userdata/mcp-audit.jsonl`；password/secret/token 脱敏。
- **小白一键接入（DSH）**：双击 `一键接入DSH.cmd` 自动写 `cordis.patch.yml`（先备份）、安装 Skill、用软件 exe 以 Node 模式启动 MCP；不需要改 JSON/装 Node；`一键移除DSH接入.cmd` 可撤回（Skill 一起移除，备份在 `~/.dsh/skill-backups/`）。

- **接入体检**：`一键体检Agent接入.cmd` / `verify-agent-mcp.ps1` 只读检查 DSH / Qoder / Trae / WorkBuddy / ZCode / Claude Desktop 的配置、路径与 Skill，并对已接入的真的启动 MCP 要工具列表；异常退出码 1 并写明卡在哪一步；`-NoProbe` 跳过启动、`-Json` 输出机器可读结果。
- **脚本安全性**：备份不覆盖；写后读回校验、失败回滚；坏 JSON / 结构不对时文件字节不变；重复接入幂等；移除可重复执行；Skill 安装/移除都有备份。
