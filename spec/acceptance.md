# 验收标准（acceptance）

> 规则：每条必须**可量化、能对照**；交付时**必须附测试证据**（脚本输出/比对数据/截图）。
> 关键项（A2）由用户真机执行，开发方不得自证。

## A1 算法往返正确性（自动比对）
测试图 3 张：①宽高非 32 倍数的常规照片；②带透明通道 PNG；③小尺寸纯色图（如 37×19）。
- 6 种模式分别执行「内存内混淆 → 解混淆」，输出与输入**逐像素 100% 一致**，6/6 通过（以 PNG 无损路径比对）。
- 方块模式对 ① 的填充结果尺寸为 32 的整数倍，且仍能 100% 解回原图区域。
- 证据：比对脚本输出（逐字节 diff 为 0 的日志）。

## A2 与手机版互相兼容（真机实测，关键项）
样本：每模式各 1 张（源图用 PNG 截图类图片）。
- 手机版混淆 → 电脑版解混淆：6/6 与原始图**逐像素 100% 一致**（若手机版存 JPG 则按 PSNR ≥ 40dB 判定）。
- 电脑版混淆 → 手机版解混淆：6/6 还原成功（人工确认，附前后截图）。
- 证据：样本文件 + 比对脚本输出 + 手机截图（≥6 张）。
- 说明：PE1/PE2 若首次不一致，用样本定位并修正链式实现后重测，直到 6/6 通过。

## A3 尺寸与保存格式规则
- `b` 模式：100×50 输入 → 128×64 输出（填充到 32 倍数，不裁剪）。
- `gilbert`：保存为 `.jpg`，画质参数 95；`c/c2/pe1/pe2` 保存为 `.png`，尺寸与输入一致。
- 证据：文件列表 + 文件头/尺寸读取输出。

## A4 批量与容错
- 一次导入 ≥20 张（其中 1 张故意损坏/非图片）：整批完成，损坏项被跳过并计入失败汇总，其余全部成功且可解回。
- 输出文件命名符合「原文件名+混淆/解混淆后缀」，不覆盖已有文件（重名自动加序号）。
- 证据：批量结果目录截图 + 汇总信息截图。

## A5 交互能力
- 拖入 1 个文件夹 → 自动载入其中所有支持的图片。
- 剪贴板粘贴 1 张图 → 可处理并复制结果回剪贴板。
- 模式切换时密钥输入框自动切换为「字符串 / 0~1 小数 / 隐藏」三态（gilbert 隐藏）。
- 证据：操作录屏或逐项截图。

## A6 离线与绿色免安装
- 断网实测：全部功能可用（附断网状态截图）。
- 把整个软件文件夹拷到另一台 Windows 10/11 电脑，双击即可运行，无需任何安装。
- 证据：另一台电脑启动成功的截图。

## A7 性能参考（非硬性，仅记录）
- 4000×3000（1200 万像素）图片单张混淆耗时 ≤ 10 秒（附耗时显示截图）。

## A8 交付物清单
- 免安装文件夹 + 压缩包（命名含版本号，如 `番茄图片混淆-桌面版-v1.0.0-win64.zip`）。
- 面向非技术用户的使用说明（含：每种模式说明、密钥规则、必须保持尺寸一致的注意事项）。
- 未跑通的验收项不得标为通过；报告需列出「已通过 / 未通过 / 未执行」。

## A9 扩展性（新增工具的成本）
- 复制 `app/src/tools/_template/` 改名为新工具 + 在 `shell/registry.js` 加一行后：左侧自动出现新工具入口、可正常切换与使用，**不需要修改任何既有工具代码**。
- 切换工具 20 次无内存/事件泄漏迹象（临时 URL、计时器被清理；操作可复现）。
- 证据：按 `docs/新增工具指南.md` 现场加一个"示例工具"的录屏或截图 + 前后 git diff（应只涉及新增文件与 registry 一行）。
- 说明：本期只验证"能低成本加入"，不要求实现压缩/PDF/视频等具体工具。
- 注：PDF 转格式工具已按本模板立项，其验收见 A10–A14。

## A10 PDF → 图片（PDF 工具）
- 3 页含中文文字的 PDF → 导出 PNG：页数 3/3、分辨率与所选档位一致、文字无缺失（附导出图截图）。
- 扫描件 PDF（纯图片页）导出同样成功；指定页范围（如 `1-2`）只导出对应页。
- 证据：导出文件列表 + 打开截图。

## A11 图片 → PDF（PDF 工具）
- 5 张图（JPG+PNG 混合）→ 合成 1 份 PDF：页数 5、顺序与列表一致、阅读器打开正常。
- JPG 为直嵌（生成文件大小接近原图之和，无二次压缩劣化）。
- 证据：生成的 PDF + 页数与文件大小读数。

## A12 合并 / 拆分 / 提取页（PDF 工具）
- 合并 3 份 PDF（3+2+1 页）→ 6 页且顺序正确。
- 拆分：6 页 PDF → 6 个单页文件。
- 提取：从 6 页抽 `1-2,5` → 3 页新文件，渲染成图后与源页视觉比对一致。
- 证据：文件清单 + 渲染比对截图。

## A13 Office→PDF 与 PDF→Word（PDF 工具，含加装包路径）
- 未装加装包：`.docx` 走内置降级成功导出 PDF；`.doc`/`.xls` 提示需加装包；PDF→Word 提示需加装包（不降级）。
- 已装加装包：`.docx`/`.xlsx` → PDF 成功；PDF→Word 成功且单栏文档打开正常；转换命令带 `writer_pdf_import` 过滤器。
- 证据：两种状态下的操作截图 + 产出文件。

## A14 离线与绿色（PDF 工具）
- 断网下全部方向可用（加装包为本地文件）。
- 加装包目录存在与否均能正常启动软件，界面正确显示「已安装 / 未安装」及说明。
- 证据：断网截图 + 两种状态启动截图。

## A15 版本号可见性
- 软件界面左上角显示版本徽章（如 `v1.1.0`）、窗口标题栏含版本号、帮助弹窗「关于」显示版本与内核信息。
- 打包产物显示的版本号与 `package.json` 一致；换新版本后一眼可辨。
- 证据：界面截图（含徽章与帮助弹窗）。

## A16 图片压缩（新工具）
- 1 张 ≥2MB 的 JPG：选「WebP / 画质 82」压缩后体积下降 ≥50%，产物可正常打开（附前后大小读数与截图）。
- 「目标大小 ≤500KB」模式：实得大小 ≤500KB×1.15，或如实提示未能达标。
- 批量 3 张以上：逐张显示 原→新 大小；不覆盖原文件（重名加序号）。
- 证据：自检脚本输出 + 界面截图。

## A17 图片变清晰（新工具）
- 对同一张样图执行「一键变清晰」：锐度指标（拉普拉斯方差）较原图提升 ≥20%（脚本输出）。
- 预览可切换原图/处理后；批量保存产物尺寸/格式正确（JPG→JPG、PNG→PNG）。
- 证据：脚本指标输出 + 前后对比截图。

## A18 图片格式转换（新工具）
- PNG → JPG/WebP/BMP/ICO/TIFF/GIF/AVIF 各转 1 次：产物**文件头合法**且可被解码（自检脚本逐个回读校验）。
- JPG → PNG/WebP 往返成功；ICO 内含多尺寸且能作为图标被系统识别（人工打开确认）。
- 不支持格式（HEIC）给出明确提示而非崩溃。
- 证据：自检脚本输出 + 产物截图。

## A19 视频格式转换（新工具，需 ffmpeg 加装包）
- 未放 ffmpeg 时：工具显示「未检测到 ffmpeg」与放置说明。
- 有 ffmpeg 时：MP4 → WebM / MKV / MOV / AVI 各 1 次成功；产物可被 ffmpeg 再次解码（自检脚本校验），视频时长与分辨率符合预期。
- 进度百分比随处理推进；取消能立即结束任务且不留残file（自检或人工确认）。
- 证据：自检脚本输出（含转码耗时）+ 界面截图。

## A20 动图与视频互转（新工具，需 ffmpeg 加装包）
- 动图（GIF）→ MP4：产物可播放，时长与源一致（±0.2s）。
- 视频 → GIF / WebP 动图 / APNG 各 1 次成功；「聊天表情·压缩」预设（240 宽 / 10 帧 / ≤2MB）产出 ≤2MB 或如实提示未能达标。
- 动图 → 动图（压缩）可用。
- 证据：自检脚本输出 + 产物截图。

## A21 ffmpeg 加装包随包与许可
- 免安装包内含 `addons/ffmpeg/ffmpeg.exe`、`LICENSE.txt`、`说明.txt`（版本/来源/许可）；缺失时软件仍可启动，仅视频类工具提示需加装。
- 证据：打包产物目录截图 + 许可文件内容。

## A22 AI 放大（超分，图片变清晰；需 Vulkan 显卡）
- 「图片变清晰」预设里出现 3 个 AI 放大选项；选中后界面显示加装包状态与**硬件要求提示（Vulkan / 纯 CPU 不可用 / 速度参考）**。
- 自检：96×64 图 AI 放大 2 倍 → 产出 192×128、PNG 可解码、耗时记录在案（本机约 1.6 秒）；
  无加装包的机器上该项按「跳过」记录，不计失败。
- 无 Vulkan / 驱动过旧时给出明确文案，不静默失败。
- 证据：`%TEMP%\tomato-media-test.json` 的 `checks.ai` + 界面截图（预设与提示条）。

## A23 左侧分组折叠（工具箱框架）
- 四个分组标题带图标、名称与数量；**默认全部收起**（从没设置过时只显示分类标题与数量，子项不显示）。
- 点一下收起、再点一下展开，过程是**平滑高度过渡**（自动测试采样中间高度，确认不是瞬间跳出）。
- 用户的收起/展开选择写入 `settings.collapsedGroups`，重启后保持；切到某工具时其所在分组临时展开（不覆盖用户偏好）。
- 未声明 `group` 的工具落在「其它」组。
- 证据：界面自动测试 `checks.分组折叠`（默认态断言 + 展开采样高度 + 图标清单）与 `checks.分组折叠记忆`（设置落盘）+ 截图。

## A24 语音转文字（第九个工具，需 asr 加装包）
- 中文语音（测试用离线合成夹具，内容已知）识别成功：文本非空且包含关键词；落盘的 `.txt` 内容与返回文本一致、不含时间戳。
- 字幕模式产出合法 SRT（含 `-->` 时间戳行与递增序号）；「文本+字幕」模式同时产出两个文件。
- 带语音的视频（mp4）走「提取音轨 → 识别」链路成功（`checks.video`）。
- 无效文件（文本冒充音频）给出可读错误，不崩溃、不产出空文件。
- 批量 2 个文件（含视频）完成；进度出现与收敛；清空生效。
- 证据：`%TEMP%\tomato-asr-test.json` 与 `%TEMP%\tomato-asr-ui-test.json` 的 checks + 界面截图。

## A25 工具页状态保持 + 组件库动效（v1.8.0）
- 切走再切回同一工具：已选文件列表与张数、当前选中项、预览画面、输入内容、滚动位置、顶栏提示与参数信息**全部保持**（不重置、不消失），且工具仍可正常操作。
- 同一时刻文档里只挂载当前工具的页面；切走的页面保留在内存（不销毁、不重新挂载）。
- 通用组件集中在 `shell/components.css`，动效节奏统一走 `theme.css` 令牌；页面切换、分组折叠、弹窗开合、按钮悬停/按压均有平滑过渡，视觉与主题一致。
- 系统开启「减少动态效果」时动效降为瞬时，功能不受影响。
- 证据：界面自动测试 `checks.stateKeep`（切走再切回的张数/画布尺寸/顶栏提示断言 + 切回后仍能操作）+ 截图。
