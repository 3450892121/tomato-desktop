# 验收标准（acceptance）

> 规则：每条必须**可量化、能对照**；交付时**必须附测试证据**（脚本输出/比对数据/截图）。
> 关键项（A2）由用户真机执行，开发方不得自证。

## A1 算法往返正确性（自动比对）
测试图 3 张：①宽高非 32 倍数的常规照片；②带透明通道 PNG；③小尺寸纯色图（如 37×19）。
- 6 种模式分别执行「内存内混淆 → 解混淆」，输出与输入**逐像素 100% 一致**，6/6 通过（以 PNG 无损路径比对）。
- 方块模式对 ① 的填充结果尺寸为 32 的整数倍，且仍能 100% 解回原图区域。
- 证据：比对脚本输出（逐字节 diff 为 0 的日志）。

## A2 与手机版互相兼容（真机实测，关键项）
样本：每模式各 1 张（源图用 PNG 截图类图片）。
- 手机版混淆 → 电脑版解混淆：6/6 与原始图**逐像素 100% 一致**（若手机版存 JPG 则按 PSNR ≥ 40dB 判定）。
- 电脑版混淆 → 手机版解混淆：6/6 还原成功（人工确认，附前后截图）。
- 证据：样本文件 + 比对脚本输出 + 手机截图（≥6 张）。
- 说明：PE1/PE2 若首次不一致，用样本定位并修正链式实现后重测，直到 6/6 通过。

## A3 尺寸与保存格式规则
- `b` 模式：100×50 输入 → 128×64 输出（填充到 32 倍数，不裁剪）。
- `gilbert`：保存为 `.jpg`，画质参数 95；`c/c2/pe1/pe2` 保存为 `.png`，尺寸与输入一致。
- 证据：文件列表 + 文件头/尺寸读取输出。

## A4 批量与容错
- 一次导入 ≥20 张（其中 1 张故意损坏/非图片）：整批完成，损坏项被跳过并计入失败汇总，其余全部成功且可解回。
- 输出文件命名符合「原文件名+混淆/解混淆后缀」，不覆盖已有文件（重名自动加序号）。
- 证据：批量结果目录截图 + 汇总信息截图。

## A5 交互能力
- 拖入 1 个文件夹 → 自动载入其中所有支持的图片。
- 剪贴板粘贴 1 张图 → 可处理并复制结果回剪贴板。
- 模式切换时密钥输入框自动切换为「字符串 / 0~1 小数 / 隐藏」三态（gilbert 隐藏）。
- 证据：操作录屏或逐项截图。

## A6 离线与绿色免安装
- 断网实测：全部功能可用（附断网状态截图）。
- 把整个软件文件夹拷到另一台 Windows 10/11 电脑，双击即可运行，无需任何安装。
- 证据：另一台电脑启动成功的截图。

## A7 性能参考（非硬性，仅记录）
- 4000×3000（1200 万像素）图片单张混淆耗时 ≤ 10 秒（附耗时显示截图）。

## A8 交付物清单
- 免安装文件夹 + 压缩包（命名含版本号，如 `番茄图片混淆-桌面版-v1.0.0-win64.zip`）。
- 面向非技术用户的使用说明（含：每种模式说明、密钥规则、必须保持尺寸一致的注意事项）。
- 未跑通的验收项不得标为通过；报告需列出「已通过 / 未通过 / 未执行」。
