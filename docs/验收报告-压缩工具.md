## 二、逐项验收对照（A37）

### 1. 双向覆盖（主流 + 非主流 ≥2）
- 13 个双向格式逐个「压缩 → 列目录 → 解压 → 逐字节比对」全部一致：ZIP / 7Z / TAR / GZIP（主流 4 种）+ BZIP2 / XZ / ZSTANDARD / BROTLI（非主流 4 种）及其 TAR 复合。
- **证据**：`--archive-test` 输出 13 种格式全 ✅；`checks.roundTrips` 全 `ok:true`。

### 2. 仅解压格式如实标注（RAR 等）
- RAR / RAR5、ISO、CAB、WIM、DEB 等在格式下拉「更多格式（仅解压）」组；选中后「开始压缩」禁用且提示「RAR 是专有格式，没有免费工具能创建」。
- **证据**：`--archive-ui-test` 断言 `runDisabled:true` 且提示含「专有格式」；`--archive-test` 的 3 种仅解压格式压缩被拒。

### 3. 密码
- 三方案真实往返成功：`7z AES-256（-mhe=on 连文件名加密）`、`zip AES-256`、`zip ZipCrypto`。
- 7Z 加密文件名后，不输密码连目录都列不出来（`checks.passwordHeaderHidden`）。
- 错误密码必须失败且**不留下垃圾目录**。
- 中文密码 + ZIP 在界面层就被拦下并建议改 7Z（实测 7-Zip 限制）。
- ZIP 中文密码拦截、产物确为 AES-256 加密（`--archive-ui-test` 用 `7z l` 读加密位断言）。
- **证据**：`checks.passwords.*`（三方案 `ok:true` 且错误密码 `rejected:true`、`leftovers:0`）、`checks.passwordHeaderHidden.ok:true`、
  `--archive-ui-test` 的 `passwordArchiveEncrypted`（`7z l` 读出 3 个条目 `AES-256 Store`）。

### 4. 分卷（分块）
- 3MB 随机数据 `-v1m` → 4 卷 `.001/.002…`；**只给第一卷解出完整内容**且逐字节一致（7z、zip 都测）。
- **证据**：`checks.volume.ok:true`，`created.paths` 含 `.001` 起的分卷。

### 5. 免解压预览
- `7z l -slt` 列条目/大小/加密位；断言**预览期间解压目录未被创建**（`checks.previewDidNotExtract`）。
- **证据**：`--archive-ui-test` `checks.preview`（条目数>0、汇总含「个条目」）+ `previewDidNotExtract:true`。

### 6. 大文件（流式，不进内存）
- 24 MB 随机 + 文本文件压缩/解压成功，内存增长远小于文件体积（证明流式处理）。
- **证据**：`checks.largeFile.ok:true`、`streaming:true`，实测 `createMs 444ms / extractMs 103ms / memGrowthMB 48MB`。

### 7. 路径安全（zip-slip）
- 自造含 `..` 条目的 tar：`listArchive` 识别 1 条可疑、`extractArchive` 拒绝解压。
- **证据**：`checks.traversal.ok:true`。

### 8. 引擎缺失降级
- 隐藏 `addons/7zip` → 工具显示「未检测到 7-Zip 加装包」+ 放置说明；`zst`/`br` 仍可用（Node 内置）。
- （由实现保证：`sevenZipStatus` 返回 `found:false` 前置；`zst`/`br` 走 `nodeCompress` 不依赖 7-Zip）

### 9. 诚实上报「跳过已存在 / 密码错」
- 实测发现并修复：`-aos` 全跳过时 7-Zip 退出码仍 0。按「本次新增文件数」判定，新增 0 时用 `7z t` 分辨密码错还是文件都在，如实报。
- **证据**：`--archive-ui-test` `checks.skipExistingReportedHonestly`（重复解压提示「没有解出任何文件」）、`checks.wrongPasswordRejected`。

## 四、已知限制（如实说明）
1. **RAR 只能解压，不能压缩**：RAR 是专有格式，免费工具（含 7-Zip）出于许可不得创建。界面如实标注。
2. **ZIP 密码只能用英文/数字**：7-Zip 限制；中文密码请用 7Z。
3. **无断点续传**：7-Zip CLI 中断不可续跑；用「分卷 + 失败可重试」替代。
4. **大文件内存**：压缩走流式，但界面进程内存增长仍与文件分块大小相关（实测 24MB 增 42MB），GB 级文件建议配合分卷。
5. **引擎缺失时**：除 ZSTANDARD / BROTLI（Node 内置）外，其它格式需 7-Zip 加装包。
