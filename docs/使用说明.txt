使用说明 —— 番茄图片混淆 桌面版
================================================

【这是什么】
把图片的像素按规则重新排列，别人看出不原来的内容；用相同的模式和密钥，
就能把图片完整还原。全程在本机处理，不联网，不上传任何东西。

【怎么打开】
双击文件夹里的「番茄图片混淆桌面版.exe」即可，不需要安装。
想放桌面的话，右键这个 exe → 发送到 → 桌面快捷方式。

【怎么看版本号】
软件左上角「番茄工具箱」旁边有个小徽章（如 v2.13.0），就是当前版本；
窗口标题栏和「帮助」弹窗最下方的「关于」里也都能看到。
以后拿到新版本，对比这个版本号就知道自己打开的是不是最新的。

【基本用法】
1. 添加图片：点界面上的「添加图片（可选多张）」；也可以把图片或整个文件夹
   直接拖进窗口；也可以按 Ctrl+V 粘贴剪贴板里的图片。
2. 选模式、填密钥（见下面的说明），模式下拉框和密钥框就在窗口上方。
3. 点「混淆」打乱当前这张图；想还原时点「解混淆」。
   - 第二排带「全部」字样的按钮，是对列表里所有图片一次性操作。
   - 「还原」= 把图恢复到刚打开时的样子（和键盘 Ctrl+Z 的"撤销"类似）。
   - 「清除」= 把图片列表清空。
4. 点「保存」：
   - 默认保存在原图旁边，文件名后面自动加「_混淆」或「_解混淆」；
   - 同名文件不会覆盖，会自动加(1)(2)；
   - 空间曲线混淆存成 JPG（体积小）；其他模式存成 PNG（无损）。
   - 也可以按 Ctrl+C 把当前结果复制到剪贴板（粘贴到微信、QQ 里发人）。

【六种模式和密钥】
1) 空间曲线混淆（番茄图）：不需要密钥。
   保存为 JPG，体积小；但反复"混淆→解混淆"会有画质损失。
2) 方块混淆 (B)：字符串密钥（中文也行）。
3) 像素混淆 (C)：字符串密钥。
4) 行像素混淆 (C2)：字符串密钥。
   以上三种保存为 PNG，无损，可以反复来回。
5) 兼容PE 行模式 (PE1)：0 到 1 之间的小数密钥（如 0.666）。
6) 兼容PE 行+列 (PE2)：0 到 1 之间的小数密钥。

【一定要记住的三件事】
1. 还原必须用"相同的模式 + 相同的密钥"，少一个都解不出来。
   密钥自己想一个，别忘了。
2. 不要把混淆后的图片裁剪、缩放，否则可能解不回来
   （左右或上下翻转没关系）。
3. 手机版 App「番茄图片混淆」和这个电脑版是互通的：
   手机混淆的图可以在电脑上解，电脑混淆的图也能拿到手机上解。

【设置】（左侧栏「设置」按钮）
- 方块数：方块混淆的分块数量，默认 32（和手机版一致）。
- JPG 画质：空间曲线混淆保存 JPG 的画质，默认 95。
- 默认密钥：PE1/PE2 密钥框的默认值，默认 0.666。
- 输出目录：默认"保存在原图旁边"；想固定到某个文件夹，点「选择文件夹…」按钮直接挑
  （和添加图片一样用系统选择框，不用手打路径）；点「用原图旁边」一键恢复默认。
- 每次保存前询问保存位置：默认关闭（保存更省事）。
设置会自动记住，存在软件目录的 userdata 文件夹里。

【常见问题】
Q: 点「解混淆」后图片还是乱码？
A: 多半是模式或密钥和当初混淆时不一致；确认两者都对。
   另外：空间曲线混淆的图如果是被微信等压缩过的，也可能解不干净。
Q: 保存的图和原图尺寸不一样？
A: 方块混淆遇到尺寸不是 32 的倍数时会自动补边，属正常现象。
Q: 会不会把我电脑上的图片传到网上？
A: 不会。软件没有任何联网功能，断网照样用。
Q: 想把这个软件带给别人用？
A: 把整个文件夹拷走（U盘、微信传压缩包都行），双击 exe 就能用，
   不需要装任何东西；设置也会跟着文件夹走。

【工具箱与分组】
左侧列表按用途分组显示，同类工具聚在一起，找起来更省事：
  · 图片：图片混淆、图片压缩、图片变清晰、图片格式转换、批量重命名、加水印、长图拼接、九宫格切图、文件藏图
  · 视频：视频下载、视频播放器、视频格式转换、视频压缩、动图与视频互转
  · 音频：音频格式转换、音频剪辑、语音转文字
  · 文档：PDF 转格式、文档格式转换、PDF 编辑整理、文字识别
  · 压缩：压缩与解压
  · 系统：软件卸载

【文档格式转换——老文档转新格式】
老版本的 Word/Excel/PPT（doc / xls / ppt / pps）和写字板 RTF，很多新设备、
手机预览、网页里都打不开；教务系统、办公系统导出的「Excel 文件」里还有一大批
其实是「Excel 2003 XML」的假 .xls（Excel 打开会弹格式警告，手机上常常直接报错）。
这个工具把这些老文档批量转成通用的新格式，转完手机就能直接打开：
1. 点「添加文档」（或直接拖进来），支持多选；
2. 转换目标选「智能（推荐）」就会自动配对：doc/rtf→docx、xls→xlsx、ppt/pps→pptx；
   也可以手动指定转成 Word/Excel/PPT/PDF（转 PDF 所有文档都支持）；
3. 点「开始转换」，产物和原文件放在一起，重名自动加序号，不会覆盖原文件。
说明：转换引擎是随包的 LibreOffice，离线可用；加密的文档转不了；
复杂公式、图表等转完可能和原来略有出入（文字与数据不丢）；
WPS 2000 时代的 .wps/.et/.dps 是私有格式，暂不支持（新版 WPS 存的 .wps
其实就是 docx，把后缀改成 .docx 一般就能打开）。
每个分组标题（带图标与工具数量）**点一下可以收起这一组、再点一下展开**（带平滑动画），收起状态会记住；
打开软件时默认只显示这几个分类标题、不展开里面的工具，界面清爽、一眼看清有哪些大类
（例外：软件会自动打开你排在最前面那个分组里的第一个工具、并只展开这一个分组，一进来就能用常用功能）；
要用哪个就点一下对应分类展开（点左侧任意一项即可切换工具），窗口顶部的状态栏会显示当前操作提示与结果。

【调整工具顺序（长按拖动即可）】
觉得哪个分组、哪个工具应该排前面？不用进任何模式，直接在左侧栏**按住不放**：
  · 按住（约半秒）工具条目再拖动，可以在本组内调整它的位置；
  · 按住分组标题再拖动，可以把整个分组（主项目）挪到别处；
  · 分组和工具的顺序互不影响、各自独立；拖到目标位置松手即可，顺序立即保存。
普通的快速点击不受影响：点工具还是切换工具，点分组标题还是展开/收起这一组
（想拖某组里的工具，先点一下它的标题把组展开）。
顺序会自动记住，下次打开软件还是你排的样子；排过序后左侧栏底部会出现
「↺ 恢复默认顺序」按钮，点一下可以一键改回出厂顺序（没排过序时这个按钮不显示）。
排在最前面的分组＝打开软件时的默认入口：每次启动直接进它的第一个工具、并展开它这一组。

【切来切去不会丢东西】
在工具之间来回切换时，原来那个工具里的东西都还留着：
已添加的文件列表、当前选中的那张图、填好的参数、滚动到的位置、顶部的提示文字，切回去原样还在，
不会清空、也不用重新添加。所以可以放心「这边弄一半、去那边看一眼、再切回来接着弄」。

小提示：为了不占太多内存，软件最多同时记住最近用过的 5 个工具页。
如果一口气切了 5 个以上工具，最久没用过的那一个会被自动释放；
再回到它时，里面会是空的，顶部会提示「上次的内容已自动释放」，重新添加文件即可。
（平时只在图片混淆和一两个转换工具之间来回的话，碰不到这个上限。）

【PDF 转格式（文档类）】
左侧点「📄 PDF 转格式」，上方选「方向」，共五个方向：

1) PDF → 图片：把 PDF 每一页导出成一张图片。
   选好清晰度（默认高清 2×）与格式（PNG 无损 / JPG 体积小），点「开始导出」；
   可填页码范围（如 1-3,5），留空就是全部页。
   结果存到原文件同目录的「原文件名_图片」文件夹（页001、页002…）。
2) 图片 → PDF：多张图片合成一份 PDF，列表顺序就是页序（可用 ↑↓ 调整）。
   页面可选「按原图尺寸」或「适应 A4」（A4 可设页边距）；点「合成 PDF」。
3) 合并 / 拆分 / 提取页：
   - 合并：加 2 份以上 PDF，按列表顺序合成一份；
   - 拆分：加 1 份 PDF，每页一个文件或每 N 页一个文件；
   - 提取页：加 1 份 PDF，填页码范围（如 1-3,5），抽成一个新 PDF。
4) Word/Excel → PDF：把 .docx / .xlsx 拖进来直接转换，无需装任何东西
   （内置方式，版式较简单）；想要更高保真、或要转旧版 .doc/.xls，见下面加装包。
5) PDF → Word：把 PDF 转成可编辑的 Word 文档（已随软件附带转换引擎，开箱即用；
   单栏文档效果好，复杂版式会有偏差）。

所有产出文件默认存在原文件旁边，重名自动加序号，绝不覆盖已有文件。

【LibreOffice 加装包（已随软件附带）】
用途：高保真 Word/Excel → PDF（含旧版 .doc/.xls）、PDF → Word。
本软件的完整版里已经带好了（软件目录下的 addons 文件夹就是它），
打开就能直接用，不需要你做任何安装：
      软件目录\addons\libreoffice\program\soffice.com
打开「PDF 转格式」工具，方向选 Word/Excel→PDF 或 PDF→Word 时
会显示「✓ 已检测到 LibreOffice」。
如果你只拷贝了主程序（没有 addons 文件夹），这几个功能会提示需要加装包——
把加装包压缩包解压到软件目录下（会生成 addons 文件夹）即可补齐。
说明：它来自开源软件 LibreOffice 26.2.6，随包的是裁剪版（约 0.6 GB，已去掉
      与格式转换无关的多语言拼写检查字典等）；完整原版约 1.5 GB。完全离线运行，
      不安装到系统、不写注册表；不需要了直接删掉 addons\libreoffice 文件夹即可。

【图片压缩（第三个工具，🗜️）】
左侧点「🗜️ 图片压缩」：
1. 点「添加图片」（可多选），也可以把图片或整个文件夹拖进窗口；
   支持 PNG / JPG / WebP / BMP / GIF / ICO / AVIF。
2. 选参数（默认值就能直接压）：
   - 输出格式：默认「自动」＝保持原格式；想让照片明显变小，选 JPG 或 WebP。
     （PNG 是无损格式，压不动属正常现象。）
   - 画质：越低体积越小（只对 JPG / WebP 有效），默认 82。
   - 尺寸：默认不缩放；选「最长边」填 1920，可把大图缩到最长边 1920 像素以内；
     选「按百分比」可整体缩小（如 80%）。
   - 压缩目标：默认「画质优先」；选「指定大小」填 500 KB，会自动调画质，
     实在达不到时会自动缩小尺寸来贴近目标（结果里会写明）。
3. 点「开始压缩」：每张显示「原大小 → 新大小（降幅）」；
   结果存在原图旁边（原图不动），重名自动加序号，不会覆盖任何文件。
   提示：压缩会重新编码，照片里的拍摄信息（EXIF）会被去掉（也更保护隐私）。

【图片变清晰（第四个工具，✨）】
左侧点「✨ 图片变清晰」：
1. 添加图片（可多选 / 拖文件夹 / 拖文件）。
2. 选一个预设（默认「一键变清晰」就行）：
   - 一键变清晰：日常照片，提升通透感与边缘清晰度；
   - 轻度锐化 / 强力锐化：自己控制力度（强力会放大噪点）；
   - 照片降噪 + 轻锐化：夜景、噪点多的照片选这个；
   - 清晰放大 2×：把图放大一倍并锐化（适合小图放大，细节不会凭空变多）；
   - 自定义：自己调锐化、降噪、亮度、对比度、饱和度。
3. 点「预览：处理后 / 原图」可来回切换对比；点「开始处理」批量保存，
   文件名为「原名_清晰」，存在原图旁边（JPG 存 JPG、PNG 存 PNG）。
   说明：这是「把现有的画面变得更清楚」，不能救回严重失焦或过度压缩的图。
4. 预设里的「AI 放大」是另一条路线（真·AI 超分，效果最好，文件会大很多）：
   · AI 放大 4×（照片，推荐）/ AI 放大 2×（最快）/ AI 放大 4×（动漫、插画）；
   · **硬件要求**：需要支持 Vulkan 的显卡（近几年的独立显卡、Intel/AMD 核显基本都支持），
     纯 CPU 跑不了；实测 720p 图放大 4 倍约 10 秒，核显会慢一些，大图请耐心等待；
   · 选中 AI 预设后，界面会显示「✓ 已检测到 AI 放大加装包」与硬件提示；
     若提示「未检测到加装包」或「显卡不支持 Vulkan」，改用普通锐化/清晰放大即可；
   · AI 放大的产物命名为「原名_AI放大」，同样存在原图旁边（不覆盖原图）。
   （说明：AI 放大每张要跑一次模型，所以预览区不做 AI 处理，点「开始处理」后看结果。）

【图片格式转换（第五个工具，🔄）】
左侧点「🔄 图片格式转换」：
1. 添加图片（支持 PNG / JPG / WebP / GIF / BMP / ICO / AVIF / SVG，
   以及 HEIC / HEIF / HIF 手机拍照格式——iPhone 等手机直接传原图就能转，不用先在手机上转 JPG）。
2. 选「输出格式」：
   - PNG：无损；
   - JPG：最通用（画质可调，透明部分按白底或黑底填充）；
   - WebP：体积最小（画质可调）；
   - BMP：老软件常用；
   - ICO：Windows 图标（自动内含 16~256 多个尺寸）；
   - TIFF / GIF / AVIF：需要 ffmpeg（已随软件附带）；GIF 出的是静态单帧。
   还可以填「最长边」限制尺寸。
3. 点「开始转换」：结果存在原文件旁边，重名自动加序号。
   手机竖拍的照片转出来方向也是正的（自动按拍摄方向摆正）。

【视频格式转换（第六个工具，🎬）】
左侧点「🎬 视频格式转换」：
1. 添加视频（可多选，支持 MP4 / MOV / MKV / AVI / WebM / FLV / WMV 等常见格式）。
2. 选参数：
   - 输出格式：MP4（最通用，默认）/ WebM（体积小）/ MKV / MOV / AVI；
   - 分辨率：默认「保持原样」；选 1080p/720p 等会等比缩小（不会放大）；
   - 质量：高质量 / 标准（默认）/ 小体积；
   - 可勾选「去掉声音」。
3. 点「开始转换」：界面显示百分比与速度，随时可以点「取消」；
   结果存在原视频旁边，重名自动加序号。
   说明：转换是重新编码，速度取决于电脑性能与视频长短（1 分钟 1080p 大约几十秒），
   画质会有轻微损失（属正常）；不能用来做剪辑。

【动图与视频互转（第七个工具，🎞️）】
左侧点「🎞️ 动图与视频互转」，双向都在这一个工具里：
1. 添加文件（动图 GIF / WebP 动图 / APNG 与视频可以一起加，工具会按类型分别处理）。
2. 选「输出格式」：
   - 转成动图（表情包）：GIF（推荐）/ WebP 动图 / APNG；
   - 转成视频：MP4 / WebM（把动图变成能剪辑、能发朋友圈的视频）。
3. 调参数（都有默认值，直接点运行也行）：
   - 起始时间、时长（默认 6 秒，留空 = 全程）；
   - 转成动图时：帧率（默认 15）、宽度（默认 480）、循环、目标大小上限；
     点「聊天表情·标准」或「聊天表情·压缩」可一键套用表情包常用参数
     （240 宽、12/10 帧、分别限制 5MB / 2MB 以内，超出时会自动降档压缩）。
   - 转成视频时：分辨率（保持 / 1080p / 720p）、帧率（保持 / 30）。
4. 点「开始处理」：结果存在原文件旁边，重名自动加序号。
   说明：GIF 最多 256 色，渐变色会有轻微色带（正常现象）；长视频转 GIF 会比较大，
   建议用「时长」截取精彩片段。

【音频格式转换（第八个工具，🎵）】
左侧点「🎵 音频格式转换」：
1. 添加音频（支持 MP3 / WAV / FLAC / M4A / OGG / WMA / AMR / APE 等常见格式，可多选），
   也可以直接把视频（MP4 / MOV / MKV 等）拖进来——会自动把里面的声音提取出来。
2. 选「输出格式」：
   - 常用：MP3（最通用）/ M4A（苹果、手机通用）/ WAV（无损）/ FLAC（无损、体积小）/ OGG / Opus（体积最小）；
   - 更多：WMA / AMR（手机录音）/ AAC / 苹果无损（AIFF、ALAC）/ WavPack / TTA /
     AC3 / EAC3 / MP2 / Speex / AU / W64 / RealAudio，共 15 种。
3. 选「音质」：高品质 / 标准（默认）/ 省空间；选无损格式（WAV、FLAC 等）时
   音质会自动变灰——无损格式不需要选音质。
4. 点「开始转换」：显示进度、可随时取消；结果存在原文件旁边，重名自动加序号。

【软件卸载（🧹，启动卸载工具）】
左侧点「🧹 软件卸载」——把不想要的软件连同残留一次清掉：
1. 点「打开卸载工具（管理员）」：系统会弹一次权限确认框，点「是」。
   （卸载程序、清理注册表都需要管理员权限，这是系统规定的；点「否」就不会启动，界面会如实提示。）
2. 在弹出的卸载工具（HiBit Uninstaller，随本软件附带）里找到要卸的程序：
   · 选中后点「卸载」，先让程序自带的卸载程序跑完；
   · 卸载完会弹「残留扫描」，逐项看一眼再删——拿不准的公共目录（如共享运行库）不要删；
   · 卸载程序损坏或找不到时，用「强制卸载」；要清理多个软件可以先多选再「卸载所选」。
3. 用完直接关掉那个窗口就行，本软件这边不用再做别的操作。

  来源与版本见 软件目录\addons\hibit\说明.txt）。它不写系统目录，自己的设置由它自己保存。

  把 addons\hibit 放回软件目录、再点「重新检测」即可；其它工具不受影响。

【外观：浅色 / 深色 / 跟随系统】

【任务中心（顶栏「任务」按钮）】
所有工具的批量任务都会出现在这里，一处就能看到进度：
- 顶栏「任务」按钮上的数字 = 还没跑完的任务数（0 时不显示）。
- 点开可以看到：进行中 / 排队 / 完成 / 失败的数量、总进度条、每个任务的进度与耗时、
  成功的输出位置或失败原因。
- 可以在这里取消某个任务、重试失败的任务、全部取消、清空已完成。
- **切走工具页任务不会停**：你可以放心去用别的工具，后台任务照常跑完。

- 导入：在新电脑上选中这个文件，设置立刻恢复（只恢复本软件认识的设置项，
  别的文件不会被乱写进来）。
