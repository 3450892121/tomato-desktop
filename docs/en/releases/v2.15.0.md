## Highlights

### 1. One-click MCP setup (DSH first; MCP is general-purpose)

Double-click **`一键接入DSH.cmd`** in the app folder, then fully quit and restart DeepSeek Harness.

The script:

- writes `~/.dsh/profiles/*/cordis.patch.yml` (with a backup);
- installs the Skill to `~/.dsh/skills/tomato-toolbox`;
- starts MCP through the app's own executable in Node mode.

**No JSON editing, no commands, no Node.js installation.**

To undo: double-click `一键移除DSH接入.cmd` (backs up the config; keeps the Skill).

### 2. MCP security hardening (same batch as v2.14.1)

- **Path allowlist**: home / temp / app by default; other folders require `TOMATO_MCP_ALLOWED_ROOTS`.
- **Audit log**: `userdata/mcp-audit.jsonl`, with password/secret/token redaction.
- **Read-only mode**: `TOMATO_MCP_READONLY=1`.
- **No overwrite**: `archive_extract` / `file_rename_batch` reject overwrite options.
- **Clear boundary**: most tools execute immediately with no confirmation dialog; Video Download is the only human-approval gate.

## Upgrade

1. Quit the old version;
2. Extract the new zip into a new empty folder;
3. Copy the old `userdata\` into the new folder (or import settings);
4. Delete the old folder once verified.

## Compatibility

- OS: Windows 10 / 11 64-bit;
- Settings: previous `userdata/settings.json` remains compatible;
- MCP: 41 tools; Video Player and Software Uninstall are not exposed;
- Phone interoperability still needs a real-device sample.

## Known issues

- One-click setup targets DSH only; other clients still use manual JSON.
- Video Download depends on yt-dlp and can break when sites change; use "Update engine".
- AI upscale requires a Vulkan GPU.
- The app is unsigned; some antivirus products may flag it.
- No general per-write human confirmation.
