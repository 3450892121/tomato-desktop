# 兼容性变体说明（与手机版对齐的三处开关）

## 为什么会有"变体"

手机版的核心算法在 `libfqt.so`（C++，arm64）里，无法直接读出实现细节；而同一套算法在网上有多个独立实现，
个别细节存在差异。这些差异**不影响本软件自身混/解的往返正确性**（怎么选都能自己解开自己），
但**决定能否解开手机版生成的图**。因此把它们做成集中开关，等真机样本到手后一次锁定。

开关位置：[`app/src/tools/obfuscate/core/variants.js`](../app/src/tools/obfuscate/core/variants.js)

## 三处开关

| 开关 | 取值 | 当前默认 | 差异来源 | 影响范围 |
|---|---|---|---|---|
| `gilbertRounding` | `trunc` / `floor` | **trunc** | `trunc`：向零取整（C++/Rust 编译实现）；`floor`：向下取整（网页版小番茄 JS） | 实测 1600 种尺寸中约 **537 种**结果不同（约 34%），影响最大 |
| `blockVariant` | `py` / `js` | **py** | `py`：Python 参考实现 + Rust 库 pyscramble（两个独立实现互相印证）；`js`：网页版 ImageMixer | 方块混淆 (B) 的映射写法 |
| `pe1Chaining` | `single` / `chained` | **single** | `single`：全图共用一条混沌序列（网页版 + Python 一致）；`chained`：每行用上一行序列末值作初值（PicEncrypt 原版行为） | 兼容PE 行模式 (PE1) |

> 说明：PE2 的"行→列"先后顺序、以及"序列末值作下一行初值"的衔接方式，三份参考实现一致（web JS / Python / PicEncrypt），故未做开关。

## 锁定流程（拿到手机版样本后）

1. **造样本**：手机装 `番茄图片混淆.apk`，用**每种模式各混淆一张图**（建议同一张原图的副本），保存后传回电脑；
   把"原图 + 混淆图"放进同一个文件夹（命名需能配对，如 `照片.png` / `照片_混淆.png` 或 `照片混淆.png`）。
2. **跑验证**（密钥填手机里实际用的那个）：
   ```powershell
   cd app
   .\node_modules\electron\dist\electron.exe . --verify-samples <样本文件夹> --key <密钥>
   ```
3. **看结论**：输出 `verdict` 数组，每对样本给出最佳匹配：
   - `meanDiff` 接近 **0** → 命中，该条 `best.mode` + `best.variants` 就是手机版的实现；
   - 若所有 `meanDiff` 都很大（>30），说明密钥或模式填错，先核对密钥。
4. **写回开关**：把命中的取值填进 `variants.js`，例如：
   ```js
   export const VARIANTS = {
     gilbertRounding: 'floor',   // ← 若样本显示 floor 命中
     blockVariant: 'js',
     pe1Chaining: 'chained'
   };
   ```
5. **回归**：`npm test`（全绿）+ `--ui-test`（`pass: true`）→ 重新打包 → 再跑一次 A2 验证确认 6/6 命中 → 发布新版本。

## 自测记录（证明工具本身可用）

用本软件自造样本（`--make-samples`）再回验，结果：

```json
{"pair":"样本原图_c",       "best":{"mode":"c",       "variants":"{}",                                  "meanDiff":0}}
{"pair":"样本原图_gilbert", "best":{"mode":"gilbert", "variants":"{\"gilbertRounding\":\"trunc\"}",      "meanDiff":0},
                            "runnerUp":{"mode":"gilbert","variants":"{\"gilbertRounding\":\"floor\"}","meanDiff":1.25}}
```

- 命中项 `meanDiff = 0`（逐像素一致），非命中项显著偏大 → 判别能力有效；
- 同一张图上 `trunc` 与 `floor` 的差值（1.25）足以被区分 → 该开关可被样本锁定。
