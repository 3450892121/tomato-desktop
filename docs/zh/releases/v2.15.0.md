## 本次重点

### 1. MCP 一键接入（DSH 首个支持；MCP 通用）

双击软件目录里的 **`一键接入DSH.cmd`**，然后完全退出并重启 DeepSeek Harness 即可。

脚本会自动：

- 写 `~/.dsh/profiles/*/cordis.patch.yml`（先备份）；
- 安装 Skill 到 `~/.dsh/skills/tomato-toolbox`；
- 用软件自己的 exe 以 Node 模式启动 MCP。

**不需要改 JSON、不需要敲命令、不需要装 Node。**

撤掉：双击 `一键移除DSH接入.cmd`（先备份配置；Skill 保留）。

### 2. MCP 安全加固（v2.14.1 同批）

- **路径白名单**：默认用户目录 / 临时目录 / 软件目录；其它目录需 `TOMATO_MCP_ALLOWED_ROOTS`。
- **审计日志**：`userdata/mcp-audit.jsonl`，password/secret/token 脱敏。
- **只读模式**：`TOMATO_MCP_READONLY=1`。
- **禁止覆盖**：`archive_extract` / `file_rename_batch` 的覆盖参数直接拒绝。
- **明确边界**：大多数工具调用即执行，没有人工确认弹窗；视频下载是唯一有人工闸门的工具。

## 升级

1. 退出正在运行的旧版本；
2. 解压新 zip 到新的空文件夹；
3. 把旧文件夹的 `userdata\` 拷到新文件夹（或「设置 → 导入」）；
4. 确认没问题后再删旧文件夹。

## 兼容性

- 系统：Windows 10 / 11 64 位；
- 配置：旧版 `userdata/settings.json` 兼容；
- MCP：41 个工具；视频播放器、软件卸载不暴露；
- 手机版互通仍需真机样本锁定。

## 已知问题

- 一键接入目前只做 DSH；其它客户端仍需手动 JSON。
- 视频下载依赖 yt-dlp，站点改版可能失败；需要「更新引擎」。
- AI 放大需要 Vulkan 显卡。
- 软件没有数字签名，部分杀毒软件会误报。
- 没有通用「每次写操作人工确认」。
