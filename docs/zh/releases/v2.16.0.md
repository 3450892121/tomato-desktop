# v2.16.0 更新说明

发布日期：2026-10-18

## 本次重点

### 1. 软件里直接接 Agent（不用再找 .cmd）

打开软件 → 左侧「**系统 → Agent 接入**」：

- 选 DSH / Qoder / Trae / WorkBuddy / ZCode，点「**接入**」；
- 点「**一键体检**」：真的启动一遍 MCP，列出工具数（正常 41 个），并告诉你卡在哪一步；
- 「移除」会二次确认，配置和 Skill 一起撤回（留备份）。

和双击软件目录里的一键脚本**完全等价**；不用改 JSON、不用敲命令、不用装 Node。

### 2. 一键接入扩到 5 个客户端

| 客户端 | 接入后要注意 |
|---|---|
| DeepSeek Harness（DSH） | 完全退出重启 DSH |
| Qoder | 完全退出重开，新开对话 |
| Trae（CN / 国际版） | 完全退出重开，点「新任务」 |
| WorkBuddy | 完全退出重开；第一次在「MCP 服务管理」点一次「信任」 |
| 智谱 ZCode | 完全退出重开；`Ctrl+K` 搜「MCP 服务器」确认开关打开 |

每个客户端都有独立的「移除」，只动自己那一条配置，先备份，不碰别的 MCP / providers。

### 3. 接入脚本更稳

- 写前备份不会互相覆盖（同一秒跑两次也会加序号）；
- 写后读回校验，失败自动回滚；
- 配置是坏 JSON 时一个字节都不改；
- 重复接入幂等；移除可重复执行；
- Skill 安装 / 移除都留备份。

## 验证

- `npm test` 全绿（含 MCP 21 项、接入脚本回归 16 项）；
- 真机 5 个客户端都做过「接入 → 对话里实际调用工具 → 移除 → 重接入」；
- `--smoke-test`：24 个工具全部渲染。

## 升级

下载新 zip，解压到新文件夹；把旧版 `userdata\` 拷过去即可。**升级后请在软件里「系统 → Agent 接入」重新点一次对应客户端的「接入」**（新文件夹名变了，旧路径会失效），再重启客户端。**release 只保留最新版**，旧版靠 git tag 回溯。
