# 工具清单

[文档中心](../README.md) · [快速开始](getting-started.md) · [详细手册](../使用说明.txt) · [English](../en/tools.md)

一共 **23 个工具**，按六组放在左侧导航。点分组标题可展开 / 收起；长按拖动可排序。

## 图片

| 工具 | 作用 | 输入 → 输出 | 备注 |
|---|---|---|---|
| 图片混淆 | 把图片打乱成看不懂的样子，或还原 | 图片 → 图片 | 六种模式；混淆/解混淆必须模式 + 密钥一致；与安卓 App 互通 |
| 图片压缩 | 按画质 / 尺寸 / 目标体积压缩 | JPG/PNG/WebP/HEIC 等 → JPG/PNG/WebP | 目标体积会尽量达标，达不到会如实提示 |
| 图片变清晰 | 锐化 / 增强 / AI 放大 | 图片 → 图片 | AI 放大需 Vulkan 显卡；Real-ESRGAN 随包 |
| 图片格式转换 | 常用格式互转 | PNG/JPG/WebP/BMP/ICO/TIFF/GIF/AVIF，另支持 HEIC 与老格式输入 | 不支持的输入会明确提示 |
| 批量重命名 | 按序号 / 替换 / 前后缀 / 日期改名 | 文件列表 → 新文件名 | 默认只预览；冲突可跳过 / 自动编号；MCP 侧禁止覆盖 |
| 加水印 | 文字 / 图片水印 | 图片 → 图片 | 位置、透明度、平铺可调 |
| 长图拼接 | 多张图纵向 / 横向拼成一张 | 图片列表 → 图片 | 自动对齐宽度 |
| 九宫格切图 | 一张图切成 9 张（或自定义行列） | 图片 → 多张图片 | 适合朋友圈 / 小红书 |
| 文件藏图 | 把任意文件藏进图片，或从图里取出 | 文件 + 封面图 → 图片；图片 → 文件 | 两种容器；PRO 模式可加密码；与「图夹」类网站/APP 双向互通 |

## 视频

| 工具 | 作用 | 输入 → 输出 | 备注 |
|---|---|---|---|
| 视频下载 | 粘贴链接下载网络视频 | URL → 视频 | **唯一联网工具**；支持抖音/小红书/B站/YouTube/央视频/直链等；引擎可更新；AI 调用需 GUI 授权 |
| 视频播放器 | 在软件内播放视频 | 视频 → 播放 | MKV/FLV/TS 优先无损换封装；AVI/WMV 等老编码自动转临时副本 |
| 视频格式转换 | MP4/WebM/MKV/MOV/AVI 互转 | 视频 → 视频 | 可取消；进度可见 |
| 视频压缩 | 按画质或目标体积压缩 | 视频 → 视频 | 目标体积用两遍编码；达不到会提示 |
| 动图与视频互转 | GIF/WebP 动图/APNG ↔ 视频 | 动图/视频 → 视频/动图 | 聊天表情预设；目标大小自动降档 |

## 与 AI / MCP 的关系

- MCP 暴露 **21 个 GUI 工具**，共 **41 个工具接口**；
- **不暴露**视频播放器、软件卸载；
- 视频下载需要 GUI 授权；其它工具调用即执行，没有确认弹窗；
- 完整参数见 [`app/mcp/README.md`](../../app/mcp/README.md) 与 [Agent 接入](agent.md)。

> 每个工具的详细操作、参数、常见问题，见随包的 [`使用说明.txt`](../使用说明.txt)。验收口径见 [`spec/acceptance.md`](../../spec/acceptance.md)。
