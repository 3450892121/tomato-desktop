# 常见问题

[文档中心](../README.md) · [快速开始](getting-started.md) · [Agent 接入](agent.md) · [English](../en/faq.md)

## 安装 / 运行

**双击没反应，或被 SmartScreen / 杀毒软件拦了？**
先看 Windows SmartScreen：点「更多信息」→「仍要运行」。少数杀毒软件会误报没有数字签名的绿色软件；把整个文件夹加入信任。除「视频下载」外不联网，可以断网验证。

**需要安装吗？怎么卸载？**
不需要安装。解压就能用；不要了直接删掉整个文件夹。配置在 `userdata\`，不会写注册表。

**支持 Windows 7 / 32 位吗？**
只测过 Windows 10 / 11 64 位；更老系统 / 32 位没有验证。

**为什么有两个名字？**
界面叫「番茄工具箱」，exe 叫 `番茄图片混淆桌面版.exe`，是同一个软件。

## 使用

**处理完的文件在哪？会覆盖原图吗？**
默认在源文件旁边，文件名加 `-混淆` / `-压缩` 等后缀；**不覆盖原文件**，重名自动加序号。也可以在设置里指定输出目录。

**混淆后为什么还原不出来？**
混淆 / 解混淆必须使用**同一个模式 + 同一个密钥**。尺寸规则：`b`（方块）模式会补到 32 的倍数，其它模式保持原尺寸。

**需要联网吗？**
除「视频下载」外都不需要。断网时其余 23 个工具照常工作。

**提示缺少加装包？**
Release 成品包已带齐 ffmpeg、LibreOffice、Real-ESRGAN、FunASR、OCR、7-Zip、yt-dlp、HiBit。若你拿到的是精简版（部分分发因许可不带 HiBit），恢复「软件卸载」见 [`加装包说明.txt`](../加装包说明.txt)。

**换电脑怎么带走？**
拷走整个文件夹；或在「设置」里导出设置，到新电脑导入。

**怎么更新？**
下载新版本，解压到新文件夹，把旧 `userdata\` 拷过去；确认没问题再删旧文件夹。

## AI / MCP

**DSH 里没有番茄工具箱的工具？**
1. 确认双击了 `一键接入DSH.cmd`；
2. **完全退出** DSH（不是关窗口）再打开；
3. 确认 `~/.dsh/profiles/*/cordis.patch.yml` 里有 `mcp-tomato-toolbox`；
4. 看 DSH 日志里的 MCP 报错。

**Qoder 里没有番茄工具箱的工具？**
1. 确认双击了 `一键接入Qoder.cmd`；
2. **完全退出** Qoder（不是关窗口）再打开，并**新开一个对话**；
3. 确认 `~/.qoder-cn/settings.json` 的 `mcpServers.tomato-toolbox` 存在；
4. Qoder 里的工具名前缀是 `mcp__tomato_toolbox__`（下划线）。

**Trae / WorkBuddy / ZCode 里没有工具？**
- **Trae**：确认双击了 `一键接入Trae.cmd`，完全退出重开，并且是**新任务/新对话**；工具名前缀是 `mcp_tomato-toolbox_`。
- **WorkBuddy**：第一次要去「专家·技能·连接器 → 连接器 → 自定义连接器 → MCP 服务管理」找到 `tomato-toolbox` 点一次「**信任**」，否则对话里看不到工具。
- **ZCode**：按 `Ctrl+K` 搜「MCP 服务器」，确认 `tomato-toolbox` 开关是打开的；如果顶部提示「当前没有可用模型」，先配好 ZCode 自己的模型（和工具箱无关）。

**软件里从哪接入 Agent？**
打开软件 → 左侧「系统 → Agent 接入」→ 点对应助手的「接入」，再点「一键体检」验证。不用去软件目录找 .cmd。

**接完不确定有没有生效？**
双击 `一键体检Agent接入.cmd`。它会检查 DSH / Qoder / Trae / WorkBuddy / ZCode 的配置和 Skill，并真的启动一遍 MCP 数工具；最后给出「正常 / 异常 / 未接入」和卡在哪。它不会改任何配置。

**为什么一直 `NEEDS_APPROVAL`？**
视频下载默认每次授权。到「视频下载」页点「允许一次」，或打开「允许 AI 助手直接下载（本次运行有效）」。

**AI 说「不在允许范围」？**
MCP 默认只允许用户目录 / 临时目录 / 软件目录。把目标目录加进 `TOMATO_MCP_ALLOWED_ROOTS`，或把文件放到允许目录。

**AI 会自己改视频下载授权吗？**
不会。授权文件只由 GUI 写，MCP 只读。

**AI 调用会弹窗确认吗？**
大多数不会。只有视频下载有授权闸门；其它工具调用即执行。重要任务先让 AI 给计划 / 预览，批量重命名默认只预览。

**能只让 AI 查询、不改文件吗？**
设 `TOMATO_MCP_READONLY=1`。

## 其它

**视频下载某些站点失败？**
站点改版会导致解析失败；软件里有「更新引擎」入口。仍失败就等引擎更新或换链接。

**AI 放大不可用？**
需要 Vulkan 显卡；没有就退回普通锐化 / 增强。

**RAR 为什么只能解压？**
RAR 是专有格式，免费工具不能创建；界面里会标注「仅解压」。
