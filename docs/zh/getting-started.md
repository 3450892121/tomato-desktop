# 快速开始

[文档中心](../README.md) · [工具清单](tools.md) · [常见问题](faq.md) · [English](../../README.en.md)

## 1. 下载

打开 [Releases](https://github.com/3450892121/tomato-desktop/releases/latest)，下载：

```text
tomato-desktop-v2.16.0-win64.zip   （约 820 MB）
```

不要只下载源码压缩包；源码包里没有加装包，不能直接运行全部功能。

## 2. 解压

把 zip 解压到任意文件夹：

- 桌面、文档、U 盘都行；
- 路径里有中文、空格也没关系；
- 建议不要放在 `C:\Program Files`（可能需要管理员权限写 `userdata`）。

解压后目录大致是：

```text
番茄图片混淆-桌面版-v<版本>-win64\
├─ 番茄图片混淆桌面版.exe
├─ 使用说明.txt
├─ 加装包说明.txt
├─ 一键接入DSH.cmd
├─ 一键移除DSH接入.cmd
├─ 一键接入Qoder.cmd
├─ 一键移除Qoder接入.cmd
├─ 一键接入Trae.cmd
├─ 一键移除Trae接入.cmd
├─ 一键接入WorkBuddy.cmd
├─ 一键移除WorkBuddy接入.cmd
├─ 一键接入ZCode.cmd
├─ 一键移除ZCode接入.cmd
├─ 一键体检Agent接入.cmd
├─ Agent接入说明.md
├─ skills\
├─ addons\
└─ userdata\
```

## 3. 运行

双击 `番茄图片混淆桌面版.exe`。

第一次打开可能遇到：

- **Windows SmartScreen**：点「更多信息」→「仍要运行」。软件没有数字签名，这是正常提示。
- **杀毒软件误报**：把整个文件夹加入信任。软件除「视频下载」外不联网，可以断网验证。

配置和缓存都在 `userdata\`，不写注册表、不写系统目录。删掉整个文件夹就是卸载。

## 4. 第一次用建议试

1. 左侧点「图片混淆」；
2. 把图片拖进窗口，或点「添加图片」；
3. 选默认模式，点「混淆」；
4. 点「保存」。

想还原就点「解混淆」，模式 / 密钥要和混淆时一致。

其它常用：

- 图片压缩 / 格式转换；
- 文件藏图；
- PDF 转图片 / 图片转 PDF；
- 压缩与解压。

详细步骤见随包的 [`使用说明.txt`](../使用说明.txt)，或软件里点「帮助」。

## 5. 给 AI 助手用（可选）

DSH 用户：

1. 双击 `一键接入DSH.cmd`；
2. 完全退出 DSH（不是关窗口）再打开；
3. 直接说：「用番茄工具箱把这个文件夹的图片压到 500KB 以内」。

Qoder 用户：

1. **先完全退出 Qoder**；
2. 双击 `一键接入Qoder.cmd`；
3. 打开 Qoder，**新开一个对话**，说同样的话。

都不需要改 JSON、不需要装 Node。撤掉分别双击 `一键移除DSH接入.cmd` / `一键移除Qoder接入.cmd`。

其它客户端见 [Agent 接入](agent.md)。

## 6. 换电脑 / 备份

- 直接拷走整个文件夹；
- 或在「设置」里「导出设置…」，新电脑「导入设置…」；
- `userdata\settings.json` 也可以手动拷，但不建议改里面的内容。

## 7. 更新

1. 下载新版本 zip；
2. 解压到**新的空文件夹**；
3. 把旧文件夹的 `userdata\` 拷到新文件夹（或导入设置）；
4. 确认没问题后再删旧文件夹。

不要直接覆盖正在运行的程序；先退出软件。
