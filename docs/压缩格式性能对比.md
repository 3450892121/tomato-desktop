# 压缩格式性能对比与技术实现说明（工具：压缩与解压）

> 对应 `spec/modules/archive.md` 与验收 A37 的「技术实现文档 + 各格式性能对比」。
> 实测环境：本机 Windows 11 x64，7-Zip 26.03（随包加装包），Node v22.20.0（内置 zstd / brotli）。

## 一、支持格式矩阵（唯一事实来源：`src/tools/archive/core/formats.mjs`）

| id | 名称 | 扩展名 | 引擎 | 可压缩 | 可解压 | 密码 | 分卷 |
|---|---|---|---|---|---|---|---|
| `zip` | ZIP | .zip | 7z | ✅ | ✅ | AES-256 / ZipCrypto | ✅ |
| `7z` | 7Z | .7z | 7z | ✅ | ✅ | AES-256（含文件名加密 -mhe=on） | ✅ |
| `tar` | TAR | .tar | 7z | ✅（仅打包） | ✅ | ❌ | ✅ |
| `gzip` | GZIP | .gz | 7z | ✅ | ✅ | ❌ | ❌ |
| `tar.gz` | TAR.GZ | .tar.gz | 7z(tar)+7z(gz) | ✅ | ✅ | ❌ | ❌ |
| `bz2` | BZIP2 | .bz2 | 7z | ✅ | ✅ | ❌ | ❌ |
| `tar.bz2` | TAR.BZ2 | .tar.bz2 | 7z | ✅ | ✅ | ❌ | ❌ |
| `xz` | XZ | .xz | 7z | ✅ | ✅ | ❌ | ❌ |
| `tar.xz` | TAR.XZ | .tar.xz | 7z | ✅ | ✅ | ❌ | ❌ |
| `zst` | ZSTANDARD | .zst | Node zlib | ✅ | ✅ | ❌ | ❌ |
| `tar.zst` | TAR.ZST | .tar.zst | 7z(tar)+Node(zstd) | ✅ | ✅ | ❌ | ❌ |
| `br` | BROTLI | .br | Node zlib | ✅ | ✅ | ❌ | ❌ |
| `tar.br` | TAR.BR | .tar.br | 7z(tar)+Node(brotli) | ✅ | ✅ | ❌ | ❌ |
| `rar` 等 18 种 | 仅解压 | .rar .iso .cab… | 7z | ❌ | ✅ | — | — |

- **4 种主流格式（ZIP / 7Z / TAR / GZIP）全部双向**；**4 种非主流格式（BZIP2 / XZ / ZSTANDARD / BROTLI）全部双向**，满足「至少 2 种非主流」的要求。
- `zst` / `br` 走 Node 22 内置 `zlib`，**不需要 7-Zip 加装包**——引擎缺失时这两个仍可用。
- **RAR 只能解压**：RAR 是专有格式，其压缩算法未公开，7-Zip 的 unRAR 代码许可明确禁止用于制作 RAR 压缩器。界面如实标注「仅解压」，不做「改后缀伪装」这类欺骗做法。

## 二、实测性能对比

> 数据来源：`--archive-test` 与 `docs` 内的基准脚本（本机离线实测）。
> 对夹具：约 18.2 MB 的**单文件混合内容**（约 14 MB 可压缩中文文本 + 4.2 MB 不可压缩随机字节），
> "标准" 档（normal，7-Zip `-mx=5` / zstd level 6 / brotli quality 6）。

| 格式 | 产物 | 压缩率 | 压缩耗时 | 解压耗时 | 备注 |
|---|---|---|---|---|---|
| BROTLI (.br) | 400 KB | 97.8% | 28 ms | 61 ms | 文本类最优；Node 内置 |
| ZSTANDARD (.zst) | 403 KB | 97.7% | 36 ms | 73 ms | 速度/体积均衡；Node 内置 |
| XZ (.xz) | 403 KB | 97.7% | 141 ms | 106 ms | 压缩较慢、解压快 |
| 7Z (.7z) | 404 KB | 97.7% | 148 ms | 119 ms | 体积最小一族，支持加密+分卷 |
| BZIP2 (.bz2) | 410 KB | 97.7% | 527 ms | 261 ms | 压缩最慢 |
| GZIP (.gz) | 467 KB | 97.4% | 387 ms | 106 ms | 速度慢于 zip、体积略大 |
| ZIP (.zip) | 467 KB | 97.4% | 400 ms | 102 ms | 最通用（任何软件都能打开） |
| TAR (.tar) | 17.4 MB | −0% | 67 ms | 107 ms | 只打包不压缩 |

> 各 `TAR.XXX` 复合格式 ≈ 对应外层格式（多一步 tar，体积几乎相同）。
> **速度/体积权衡结论（供使用者选格式）**：
> - 想要**最小体积 + 速度快** → 7Z（最通用）或 ZSTANDARD（开箱即用）。
> - 想要**兼容所有软件** → ZIP（但文件稍大、加密密码只能是英文/数字）。
> - 想要**Linux/服务器风格** → TAR.GZ / TAR.XZ。
> - 文本类素材 → BROTLI 体积最小；已压缩过的文件（图片/视频/已有 zip）→ 任何格式都压不动，用「存储」档。

## 三、实现要点（`src/tools/archive/core/`）

**分层**：`formats.mjs`（格式矩阵）→ `params.mjs`（7-Zip 参数拼装 + 输出解析 + 错误翻译）→
`plan.mjs`（把"文件 + 参数"翻译成作业步骤，含校验）→ `engine.mjs`（真正跑 7-Zip / Node zlib）。

### 1. 用 7-Zip 做引擎，Node 内置 zlib 补 zstd/brotli
- 7-Zip（LGPL 2.1+）作为随包加装包 `addons/7zip/`；ZIP/7Z/TAR/GZIP/BZIP2/XZ 用它。
- `zstd` / `brotli` 用 Node 22 `zlib.createZstdCompress / createBrotliCompress` 流式处理，不进内存。
- **跨平台「引擎可替换」**：查找顺序 = 随包加装包 → 系统 PATH 的 `7z`/`7za` → `C:\Program Files\7-Zip\7z.exe`；换平台只需换引擎二进制，代码零改动。

### 2. 几个实测踩出来的关键细节（不是照抄文档）
- **TAR 只打包不压缩**：`-ttar .tar.gz` 只会得到纯 tar（7-Zip 不自动套 gzip，实测）；所以 `tar.gz` 等复合格式是**两步**——先 `tar` 出临时文件，再用外层算法压。
- **gzip/bzip2/xz/zst/br 是单文件流式格式**：多文件会系统报错，界面前置拦截并建议用 TAR.xxx / ZIP / 7Z。
- **密码必须命令行传 `-p` 且避免交互**：不给 `-p` 时 7-Zip 会交互式索要密码导致挂起；给空 `-p` 则立刻干净报错。子进程 stdin 一律 `ignore` 作第二道保险。
- **中文文件名必须 `-sccUTF-8`**：否则条目名按 OEM 码页输出，界面显示乱码。
- **Node 流式 zlib 的进度不能挂 `on('data')`**：那会把流切到 flowing 模式，在 `pipeline` 接上消费者前就丢掉小块数据（实测小文件压出来只剩 zstd 帧头 9 字节）。用 `Transform` 作管道中间一环计数才安全。
- **ZIP 密码只能英文/数字**：实测 7-Zip 给 ZIP 加中文密码直接「参数错误」。界面前置校验并建议改用 7Z（7Z 用 UTF-16 密码无此问题）。

### 3. 大文件与分卷（对应「断点续传或分块处理」）
- 7-Zip CLI 无断点续传，改用**分卷**：`-v<size>` 切 `.001/.002…`（仅 ZIP/7Z/TAR），解压只给第一卷即可自动接上。流式格式不支持分卷，界面禁用并说明。
- 全程流式读写，GB 级文件不进界面进程内存（大文件自检内存增长 < 256 MB）。
- 失败时删除半成品压缩包/解压产物，不骗到用户。

### 4. 安全（zip-slip 防护）
- 解压前先 `7z l -slt` 列目录，检查条目路径含 `..` 或绝对路径 → 整包拒绝并给出可读提示（含复合格式的第二趟）。
- 密码错误 / 数据损坏会在闸门或 `7z t` 校验阶段发现，报「密码错误」而非静默产出空文件。

### 5. 一个诚实上报的设计
- `-aos`（跳过已存在）时 7-Zip 会一个都不解却退出码 0。实现按「这次**新增**了几个文件」判定（解压前做文件快照），新增为 0 就用 `7z t` 分辨「密码错」还是「文件都在」，如实告知，不把"什么都没做"报成成功。

## 四、加装包随包（`pack.js` 步骤 5g）
- `addons/7zip/`：`7z.exe`（约 0.6 MB）+ `7z.dll`（约 1.9 MB）+ `License.txt` + `说明.txt`，约 2.4 MB。不进 git，打包时随主包复制，**解压即用、无需安装**。
- 缺失时：工具顶部提示「未检测到 7-Zip 加装包」+ 放置说明；`zst`/`br` 仍可用，其余格式如实标注不可用，软件不崩。
