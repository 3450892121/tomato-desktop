- 新增工具一律复制 `src/tools/_template/` 并在 `src/shell/registry.js` 登记一行，禁止直接修改既有工具或 shell 代码。
- 工具之间禁止互相 import，复用逻辑统一下沉到 `src/shared/`。
- 工具页样式只使用自身 `styles.css`，颜色/字号/间距通过 `shell/theme.css` 变量引用，不得硬编码色值。
- 默认实现纯离线；确需联网的功能（目前仅「视频下载」）必须先与用户确认。
- 提交信息采用 fix / feat / docs / chore 类型前缀，每次改动完成后立即创建 git commit。
- 敏感信息（token、密钥、凭据、账号、本机路径）严禁进 git，除 `.gitignore` 外还需在推送前手动扫描暂存区。
