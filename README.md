# 番茄工具箱 桌面版

![番茄工具箱主界面：左边是工具分类，右边是「图片混淆」](docs/images/main.png)

**一个不用安装、双击就能用的 Windows 工具箱。** 图片、视频、音频、PDF、压缩包这些日常杂活，
都收在同一个窗口里；解压即用，配置只写在软件自己的文件夹里，不碰系统。

- **给不懂技术的人用**：每个工具页里都写着怎么操作，参数有合理默认值，输出文件不会覆盖原文件。
- **基本不用联网**：除了「视频下载」（它本来就是下载网络视频），其余 22 个工具断网照常工作。
- **和手机版互通**：「图片混淆」和安卓 App「番茄图片混淆」互相能解开——电脑上打的图手机能解，
  手机打的图电脑也能解。

> **两个名字是同一个软件**：界面左上角写的是「番茄工具箱」，解压后双击的 exe 叫
> `番茄图片混淆桌面版.exe`。最早是给手机版做电脑版，后来工具越加越多，界面名就改成了工具箱。
> 两个名字都指这一个软件，不影响使用。

## 一、下载和打开（普通用户看这里）

1. 打开 [Releases](https://github.com/3450892121/tomato-desktop/releases)，下载
   `tomato-desktop-v2.13.0-win64.zip`（约 812 MB）。
2. 把压缩包解压到任意文件夹——放在桌面、文档、U 盘里都行，路径里有中文也没关系。
3. 双击解压出来的 `番茄图片混淆桌面版.exe`。

第一次打开时，Windows 可能弹出蓝色提示「Windows 已保护你的电脑」——点「更多信息」→「仍要运行」
即可。这个软件没有买数字签名，弹提示属于正常现象。

配置、缓存都写在软件文件夹里的 `userdata/`，**不写注册表、不装系统目录**；
想换电脑，把整个文件夹拷走就是同一套东西。

> 不会用？压缩包里自带 `docs/使用说明.txt`（每个工具怎么用、常见问题都写了），
> 软件里点左下角「帮助」也能看。

## 二、里面有哪些工具

一共 23 个，按六组放在左侧导航里（点分组标题可以展开 / 收起）：

| 分组 | 工具 |
|---|---|
| 图片 | 图片混淆 · 图片压缩 · 图片变清晰 · 图片格式转换 · 批量重命名 · 加水印 · 长图拼接 · 九宫格切图 · 文件藏图 |
| 视频 | 视频下载 · 视频播放器 · 视频格式转换 · 视频压缩 · 动图与视频互转 |
| 音频 | 音频格式转换 · 音频剪辑 · 语音转文字 |
| 文档 | PDF 转格式 · 文档格式转换 · PDF 编辑整理 · 文字识别 |
| 压缩 | 压缩与解压 |
| 系统 | 软件卸载 |

第一次用，建议先试这几个：

- **图片混淆 / 解混淆**：把图片打乱成看不懂的样子发给别人，对方用同样的软件（或手机 App）
  就能还原。支持单张、批量、拖进来、剪贴板粘贴。
- **图片压缩 / 图片格式转换**：照片压小、转成 JPG / PNG / WebP 等格式；手机拍的 HEIC 照片也能转。
- **文件藏图**：把任意文件藏进一张图片里，图片照样能正常打开；对方用软件就能把文件取出来。
- **PDF 与老文档**：PDF 转图片、图片转 PDF、合并拆分、加水印页码、加密解密；
  老版 Word / Excel / PPT 和「假 .xls」也能转成新格式。
- **视频下载**：粘贴链接，下载抖音 / 小红书 / B站 / YouTube 等站点的视频（唯一需要联网的工具）。
- **压缩与解压**：ZIP / 7Z / TAR 等十几种格式，支持密码、分卷、免解压预览。

每个工具都自带说明；想细看每个工具的能力和限制，见 `spec/modules/`（一个工具一个文件）。

## 三、举个例子：图片混淆怎么用

1. 左边点「图片混淆」。
2. 把图片拖进窗口，或点「添加图片（可选多张）」。
3. 选模式（默认「空间曲线混淆（番茄图）」就行），需要的话填密钥。
4. 点「混淆」，处理完点「保存」。想还原就点「解混淆」。

> 注意：混淆和解混淆要用**同一个模式、同一个密钥**，否则还原不出来。
> 尺寸规则：`b`（方块）模式会补到 32 的倍数，其余模式保持原尺寸。

## 五、常见问题

**Q：双击没反应，或者被杀毒软件拦了？**
A：先看是不是被 Windows 的 SmartScreen 拦了（点「更多信息」→「仍要运行」）。
少数杀毒软件对没有数字签名的绿色软件会误报，加信任即可。软件除「视频下载」外不联网，
可以断网验证。

**Q：需要安装吗？怎么卸载？**
A：不需要安装。解压就能用；不要了直接删掉整个文件夹。

**Q：需要联网吗？**
A：除「视频下载」外都不需要。断网时其余 22 个工具照常工作。

**Q：处理完的文件存在哪？会不会覆盖原图？**
A：默认存在原文件旁边，文件名后面加「-混淆」「-压缩」这类后缀，**不会覆盖原文件**；
重名会自动加序号。保存时也可以自己选目录。

**Q：换电脑怎么带走？**
A：把整个软件文件夹拷走即可。设置可以在「设置」里导出成一个文件，到新电脑再导入。

**Q：提示缺少加装包怎么办？**
A：Release 里的成品包已经带齐 ffmpeg、LibreOffice、Real-ESRGAN、FunASR、OCR 模型、7-Zip、yt-dlp。
只有两样受许可限制没放：HiBit 卸载工具（「软件卸载」用）和两个 HEIC 测试图。
想恢复「软件卸载」，去 HiBit 官网下载便携版放进 `addons/hibit/` 即可。详见 `docs/加装包说明.txt`。

**Q：支持 Windows 7 吗？**
A：只测过 Windows 10 / 11 64 位，更老的系统没有验证。

**Q：软件怎么更新？**
A：到 Releases 下载新版本，解压到新文件夹；旧设置可以把 `userdata/settings.json` 拷过去，
或者用「设置 → 导出 / 导入」。

## 六、已知限制

- 网站改版会让「视频下载」对某些站点解析失败（这类工具的固有风险），软件内提供「更新引擎」入口。
- 「图片变清晰」的 AI 放大需要 Vulkan 显卡；「语音转文字」是纯 CPU 推理，长音频要等。
- PDF → Word 对复杂排版会降级（提供两种输出方式，避开超大文档卡死）；带打开密码的文档要先解密。
- RAR 只能解压，不能创建（专有格式，免费工具做不了），界面里会如实标注。
- 软件没有数字签名，部分杀毒软件会误报。
- HEIC 测试图受许可限制不随仓库分发，只影响开发者跑 `--media-test` 的 HEIC 段。

## 七、给开发者

### 从源码跑起来

前置：Windows 10 / 11 64 位、Node.js 22+（自带 npm）。

```bash
cd app
npm install          # 装依赖（含 Electron）
npm start            # 打开软件窗口
npm test             # 纯逻辑单测（不需要网络，也不需要加装包）
npm run pack         # 打成免安装版，产物在 app/release/
```

中国大陆网络慢就用镜像：

```bash
npm install --registry=https://registry.npmmirror.com
# Electron 二进制走镜像（PowerShell）：
$env:ELECTRON_MIRROR = "https://registry.npmmirror.com/-/binary/electron/"
```

### 加装包（不进仓库）

ffmpeg、LibreOffice、Real-ESRGAN、FunASR、OCR 模型、7-Zip、yt-dlp、HiBit 这八个外部程序
体积约 1.5 GB、许可各异，所以**不进仓库**；打包时由 `tools/pack.js` 从 `app/addons/<名字>/` 取用。

- 放哪个版本、放在哪、缺了会怎样：见 `docs/加装包说明.txt`
- 各自的许可与随分发要尽的义务：见 `THIRD-PARTY-NOTICES.md`
- 缺某个加装包时，对应工具页会显示引导并禁用按钮，**其它工具完全不受影响**

### 目录结构

```
app/
├─ main.js / preload.js      主进程与安全桥（窗口、文件对话框、子进程、IPC）
├─ src/shell/                工具箱框架：注册表、分组导航、工具页保活、任务队列、主题、组件库
├─ src/tools/<工具名>/       一个工具一个目录：index.js（声明）+ ui.js + core/ + styles.css
│  └─ _template/             新工具空白模板
├─ src/shared/               跨工具复用：图片读写、ffmpeg、HEIC 解码、文件封装、设置
├─ vendor/xlsx/              SheetJS 单文件（含 LICENSE 与来源说明）
├─ tests/                    纯逻辑单测 + 自检与界面自动测试
├─ tools/pack.js             打包脚本（产物瘦身、快捷方式同步、设置迁移）
└─ addons/                   加装包（不入库）
docs/                        使用说明、加装包说明、README 截图
spec/                        模块规格：目标、边界、选型依据、已知限制
```

### 加一个新工具

1. 复制 `app/src/tools/_template/` 为 `app/src/tools/<工具名>/`，改 `id` / `name` / `icon` / `group` / `order`。
2. 在 `app/src/shell/registry.js` 的 `TOOLS` 里加一行 import 与一项。
3. **工具之间禁止互相 import**；确实要复用的能力抽到 `src/shared/`。
4. 样式只写在自己的 `styles.css` 里，颜色 / 字号 / 间距引用 `shell/theme.css` 的变量。
5. 新工具与新增测试文件都要加进 `tools/pack.js` 的文件白名单，否则产物里没有它们。

### 怎么验证改动

- `npm test`：纯逻辑单测；单个文件也可以 `node tests/xxx.test.mjs` 直接跑。
- 自检与界面自动测试通过 Electron 启动开关运行：

```bash
cd app
.\node_modules\electron\dist\electron.exe . --smoke-test      # 冒烟：工具数与 registry 实况一致
.\node_modules\electron\dist\electron.exe . --ui-test         # 图片混淆全流程，像素级校验
.\node_modules\electron\dist\electron.exe . --archive-test    # 压缩解压：13 种格式真实往返
```

结果写在 `%TEMP%\tomato-*.json`，看 `pass:true` / `ok:true` 判过；界面测试截图在 `%TEMP%\tomato-uitest`。
全部开关列在 `main.js` 顶部的注释里，每个工具的验证口径见 `spec/modules/` 对应模块的「测试」节。

两个注意：跑 `--ui-test` 前先清空 `userdata/settings.json`（它要求默认导航档案）；
「文件藏图」与「视频下载」的 `verified` 字段需要外部原版实现与联网更新项当裁判，
在纯净环境里 `ok:true / verified:false` 是预期结果。
